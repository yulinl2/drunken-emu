# Settings reference, part B: the sandbox keys (window 1) and the session, memory and display keys that follow them.
setting.sandbox | setting | VERIFIED | S12 | sandbox | Scope: any file. Type: object. Default: unset. Isolates Bash commands from your filesystem and network using sandboxing.
setting.sandbox-enabled | setting | VERIFIED | S12 | sandbox.enabled | Scope: any file, with limits on project and local. Type: Boolean. Default: false. Turns on sandboxing for Bash commands.
setting.sandbox-fail-if-unavailable | setting | VERIFIED | S12 | sandbox.failIfUnavailable | Scope: any file, with limits on project and local. Type: Boolean. Default: false. Exits with an error at startup if the sandbox cannot start.
setting.sandbox-auto-allow-bash-if-sandboxed | setting | VERIFIED | S12 | sandbox.autoAllowBashIfSandboxed | Scope: any file. Type: Boolean. Default: true. Runs sandboxed Bash commands without a permission prompt.
setting.sandbox-excluded-commands | setting | VERIFIED | S12 | sandbox.excludedCommands | Scope: any file, with limits on project and local. Type: array of command patterns. Default: unset. Names commands that run outside the sandbox.
setting.sandbox-allow-unsandboxed-commands | setting | VERIFIED | S12 | sandbox.allowUnsandboxedCommands | Scope: any file, with a limit on project and local. Type: Boolean. Default: true. Lets Claude retry sandbox-blocked commands unsandboxed; false enables strict sandbox mode.
setting.sandbox-filesystem | setting | VERIFIED | S12 | sandbox.filesystem | Scope: any file. Type: object. Default: unset. Controls which paths sandboxed commands can read and write.
setting.sandbox-filesystem-allow-write | setting | VERIFIED | S12 | sandbox.filesystem.allowWrite | Scope: any file, with limits on project and local. Type: array of path strings. Default: unset. Adds paths where sandboxed commands can write, beyond the defaults.
setting.sandbox-filesystem-deny-write | setting | VERIFIED | S12 | sandbox.filesystem.denyWrite | Scope: any file. Type: array of path strings. Default: unset. Blocks sandboxed commands from writing to specific paths, even inside writable directories.
setting.sandbox-filesystem-deny-read | setting | VERIFIED | S12 | sandbox.filesystem.denyRead | Scope: any file. Type: array of path strings. Default: unset. Blocks sandboxed commands from reading specific paths, such as credential files.
setting.sandbox-filesystem-allow-read | setting | VERIFIED | S12 | sandbox.filesystem.allowRead | Scope: any file, with limits on project and local. Type: array of path strings. Default: unset. Re-opens reads for paths inside regions that denyRead blocks.
setting.sandbox-filesystem-allow-managed-read-paths-only | setting | VERIFIED | S12 | sandbox.filesystem.allowManagedReadPathsOnly | Scope: managed. Type: Boolean. Default: false. Honors only managed allowRead entries, so developers cannot re-open paths.
setting.sandbox-filesystem-disabled | setting | VERIFIED | S12 | sandbox.filesystem.disabled | Scope: user or managed; managed only in some cases. Type: Boolean. Default: false. Skips filesystem isolation while keeping network isolation.
setting.sandbox-ignore-violations | setting | VERIFIED | S12 | sandbox.ignoreViolations | Scope: any file, with limits on project and local. Type: object mapping command substrings to violation substrings. Default: unset. Silences expected sandbox violation reports, such as refused path probes.
setting.sandbox-enable-weaker-nested-sandbox | setting | VERIFIED | S12 | sandbox.enableWeakerNestedSandbox | Scope: any file, with limits on project and local. Type: Boolean. Default: false. Lets the Linux sandbox run in an unprivileged Docker container, which reduces security.
setting.sandbox-enable-weaker-network-isolation | setting | VERIFIED | S12 | sandbox.enableWeakerNetworkIsolation | Scope: any file, with limits on project and local. Type: Boolean. Default: false. Lets macOS sandboxed commands reach the system TLS trust service.
setting.sandbox-allow-apple-events | setting | VERIFIED | S12 | sandbox.allowAppleEvents | Scope: user or managed. Type: Boolean. Default: false. Lets sandboxed macOS commands send Apple Events, which removes code-execution isolation.
setting.sandbox-ripgrep | setting | VERIFIED | S12 | sandbox.ripgrep | Scope: user or managed. Type: object with command and optional args. Default: unset. Points the sandbox at your own ripgrep binary.
setting.sandbox-bwrap-path | setting | VERIFIED | S12 | sandbox.bwrapPath | Scope: managed. Type: string, absolute path. Default: unset. Points the sandbox at a bubblewrap binary installed outside PATH.
setting.sandbox-socat-path | setting | VERIFIED | S12 | sandbox.socatPath | Scope: managed. Type: string, absolute path. Default: unset. Points the sandbox network proxy at a socat binary installed outside PATH.
setting.sandbox-credentials | setting | VERIFIED | S12 | sandbox.credentials | Scope: any file. Type: object. Default: unset. Declares credential files and environment variables to protect from sandboxed commands.
setting.sandbox-credentials-files | setting | VERIFIED | S12 | sandbox.credentials.files | Scope: any file; no mask entries from project or local. Type: array of objects. Default: unset. Protects credential files with deny or mask modes.
setting.sandbox-credentials-env-vars | setting | VERIFIED | S12 | sandbox.credentials.envVars | Scope: any file; no mask entries from project or local. Type: array of objects. Default: unset. Protects environment variables with deny or mask modes.
setting.sandbox-credentials-allow-plaintext-inject | setting | VERIFIED | S12 | sandbox.credentials.allowPlaintextInject | Scope: user or managed. Type: Boolean. Default: false. Allows mask substitution on plain HTTP requests as well as HTTPS.
setting.sandbox-credentials-aws-pairs | setting | VERIFIED | S12 | sandbox.credentials.awsPairs | Scope: user or managed. Type: array of objects. Default: unset. Groups masked variables into one AWS credential for SigV4 re-signing.
setting.sandbox-credentials-sigv4 | setting | VERIFIED | S12 | sandbox.credentials.sigv4 | Scope: user or managed. Type: object. Default: unset (every form denies). Chooses whether the proxy fails or forwards AWS request forms it cannot re-sign.
setting.sandbox-network | setting | VERIFIED | S12 | sandbox.network | Scope: any file. Type: object. Default: unset. Controls which hosts, ports and sockets sandboxed commands can reach.
setting.sandbox-network-allow-unix-sockets | setting | VERIFIED | S12 | sandbox.network.allowUnixSockets | Scope: any file, with limits on project and local. Type: array of strings. Default: unset. Lists Unix socket paths that sandboxed commands can connect to on macOS.
setting.sandbox-network-allow-all-unix-sockets | setting | VERIFIED | S12 | sandbox.network.allowAllUnixSockets | Scope: any file, with limits on project and local. Type: Boolean. Default: false. Lets sandboxed commands connect to every Unix socket, the only option on Linux.
setting.sandbox-network-allow-local-binding | setting | VERIFIED | S12 | sandbox.network.allowLocalBinding | Scope: any file, with limits on project and local. Type: Boolean. Default: false. Lets macOS sandboxed commands listen on ports and reach localhost.
setting.sandbox-network-allow-mach-lookup | setting | VERIFIED | S12 | sandbox.network.allowMachLookup | Scope: any file, with limits on project and local. Type: array of strings. Default: unset. Lists extra XPC and Mach service names the macOS sandbox may look up.
setting.sandbox-network-allowed-domains | setting | VERIFIED | S12 | sandbox.network.allowedDomains | Scope: any file, with limits on project and local; managed only if allowManagedDomainsOnly is set. Type: array of strings. Default: unset. Pre-allows outbound domains for sandboxed commands so that no prompt appears.
setting.sandbox-network-denied-domains | setting | VERIFIED | S12 | sandbox.network.deniedDomains | Scope: any file. Type: array of strings. Default: unset. Blocks domains for sandboxed outbound traffic, overriding allowedDomains.
setting.sandbox-network-strict-allowlist | setting | VERIFIED | S12 | sandbox.network.strictAllowlist | Scope: user or managed. Type: Boolean. Default: false. Denies sandboxed access to hosts outside the allowlist instead of prompting.
setting.sandbox-network-allow-managed-domains-only | setting | VERIFIED | S12 | sandbox.network.allowManagedDomainsOnly | Scope: managed. Type: Boolean. Default: false. Locks the network allowlist to the domains that managed settings define.
setting.sandbox-network-http-proxy-port | setting | VERIFIED | S12 | sandbox.network.httpProxyPort | Scope: any file, unless other sandbox settings limit it. Type: number. Default: unset. Points the sandbox at your own HTTP proxy instead of Claude Code's.
setting.sandbox-network-socks-proxy-port | setting | VERIFIED | S12 | sandbox.network.socksProxyPort | Scope: any file, unless other sandbox settings limit it. Type: number. Default: unset. Points the sandbox at your own SOCKS5 proxy instead of Claude Code's.
setting.sandbox-network-tls-terminate | setting | VERIFIED | S12 | sandbox.network.tlsTerminate | Scope: user or managed. Type: object with optional caCertPath and caKeyPath. Default: unset. Makes the sandbox proxy terminate TLS to inspect HTTPS contents (experimental).
setting.auto-compact-enabled | setting | VERIFIED | S12 | autoCompactEnabled | Scope: any file. Type: Boolean. Default: true. Compacts the conversation automatically as context nears its limit.
setting.auto-compact-window | setting | VERIFIED | S12 | autoCompactWindow | Scope: any file. Type: number of tokens, from 100000 to 1000000. Default: unset. Sets how full context gets before automatic compaction runs.
setting.auto-memory-directory | setting | VERIFIED | S12 | autoMemoryDirectory | Scope: any file. Type: string, directory path. Default: unset. Stores auto memory in a chosen directory instead of the per-project default.
setting.auto-memory-enabled | setting | VERIFIED | S12 | autoMemoryEnabled | Scope: any file. Type: Boolean. Default: true. Turns auto memory on or off; false stops Claude reading or writing it.
setting.claude-md | setting | VERIFIED | S12 | claudeMd | Scope: managed. Type: string. Default: unset. Injects CLAUDE.md-style instructions as organization-managed memory.
setting.claude-md-excludes | setting | VERIFIED | S12 | claudeMdExcludes | Scope: any file. Type: array of strings. Default: unset. Skips specific CLAUDE.md files when Claude Code loads memory.
setting.env | setting | VERIFIED | S12 | env | Scope: any file. Type: object mapping names to strings. Default: unset. Sets environment variables for every session and for the subprocesses it starts.
setting.file-checkpointing-enabled | setting | VERIFIED | S12 | fileCheckpointingEnabled | Scope: any file. Type: Boolean. Default: true. Snapshots files before each edit so that /rewind can restore them.
setting.idle-compaction | setting | VERIFIED | S12 | idleCompaction | Scope: any file. Type: Boolean. Default: true. Compacts long idle conversations shortly before the prompt cache expires.
setting.plans-directory | setting | VERIFIED | S12 | plansDirectory | Scope: any file. Type: string, path relative to the project root. Default: unset (~/.claude/plans). Chooses where plan files written in plan mode are stored.
setting.skill-listing-budget-fraction | setting | VERIFIED | S12 | skillListingBudgetFraction | Scope: any file. Type: number, above 0 and at most 1. Default: 0.01. Caps the share of the context window that the skill listing may use.
setting.skill-listing-max-desc-chars | setting | VERIFIED | S12 | skillListingMaxDescChars | Scope: any file. Type: number of characters. Default: 1536. Caps the characters of each skill's description and when_to_use text that are shown.
setting.task-output-max-chars | setting | REMOVED | - | taskOutputMaxChars | Scope and type not stated. Removed in v2.1.277 with the TaskOutput tool; setting it has no effect. See tool.task-output.
setting.auto-continue-at-usage-limit | setting | VERIFIED | S12 | autoContinueAtUsageLimit | Scope: user or managed. Type: Boolean. Default: true. Continues the task automatically after a claude.ai usage limit resets.
setting.auto-scroll-enabled | setting | VERIFIED | S12 | autoScrollEnabled | Scope: any file. Type: Boolean. Default: true. Follows new output to the bottom in fullscreen rendering.
setting.bash-edit-diff-enabled | setting | VERIFIED | S12 | bashEditDiffEnabled | Scope: user or managed; a true value in a repository file is ignored. Type: Boolean. Default: unset. Records files changed during Bash commands in Git repositories, for diffs and hooks.
setting.company-announcements | setting | VERIFIED | S12 | companyAnnouncements | Scope: any file. Type: array of strings. Default: unset. Shows organization announcements at startup, picking one at random.
setting.default-shell | setting | VERIFIED | S12 | defaultShell | Scope: any file. Type: string, "bash" or "powershell". Default: bash (powershell on Windows without Bash). Chooses whether Bash or PowerShell runs the ! prefix shell commands.
setting.dialog-expiry | setting | VERIFIED | S12 | dialogExpiry | Scope: user or managed. Type: string, "60s", "5m", "10m" or "never". Default: "5m". Sets how long forwarded dialogs wait before cancelling with their default.
setting.editor-mode | setting | VERIFIED | S12 | editorMode | Scope: any file. Type and default not captured, because the extraction cut off at this entry. Chooses the key binding mode for the input prompt.
