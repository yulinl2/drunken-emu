# Glossary terms (kind term) and hook events (kind hook, one node per event).
term.harness | term | VERIFIED | S2, S3 | Harness | The runtime around the model: the tool loop, permissions, hooks, memory files, settings and integrations. Claude Code is the harness that runs the model. Related: [[term.hook]], [[term.settings-scope]].
term.built-in-tool | term | VERIFIED | S6 | Built-in tool | A tool the runtime provides under a fixed name. Permission rules, subagent tool lists and hook matchers all use that name. Example: [[tool.bash]].
term.deferred-tool | term | SESSION | S8 | Deferred tool | A tool whose schema loads only after ToolSearch fetches it. Calling it before that fails with an input-validation error. See [[term.toolsearch]].
term.toolsearch | term | SESSION | S8 | ToolSearch | The tool that loads deferred schemas, by exact name with select: or by keyword. See [[tool.tool-search]].
term.connector | term | SESSION | S8 | Connector | A claude.ai integration, such as GitHub or Gmail, exposed as tools in this session. Example: [[tool.github-actions-get]].
term.mcp-server | term | INDEX | S1 | MCP server | A Model Context Protocol server that adds tools, resources or prompts. See [[mcp.overview]].
term.hook | term | VERIFIED | S2 | Hook | A handler the runtime runs at a named event. Handler types: command, http, mcp_tool, prompt and agent (experimental). See [[hook.pre-tool-use]] and [[hook-rule.handler-command]].
term.matcher | term | VERIFIED | S2 | Matcher | The hook field that selects which tool or source an event applies to. See [[hook-rule.matcher-empty]] and [[hook-rule.matcher-regex]].
term.skill | term | VERIFIED | S5 | Skill | A folder with a SKILL.md file (frontmatter plus instructions) that runs as /name. Example: [[skill.data-analyze]].
term.subagent | term | VERIFIED | S6 | Subagent | A child agent with its own context window, started by the Agent tool. It returns one final result. See [[tool.agent]].
term.fork | term | VERIFIED | S6 | Fork | A subagent that inherits the full parent conversation. See [[tool.agent]].
term.teammate | term | VERIFIED | S6 | Teammate | An agent-team member, started by the Agent tool when agent teams are on. See [[feature.agent-teams]].
term.permission-mode | term | VERIFIED | S4 | Permission mode | The policy that decides when Claude asks before acting. Example: [[permission-mode.default]].
term.permission-rule | term | VERIFIED | S6 | Permission rule | A ToolName(specifier) entry in an allow, ask or deny list. See [[permission-rule.form]].
term.permission-column | term | VERIFIED | S6 | Permission column | In the tools reference, Yes means the tool asks for approval in Manual mode for paths inside the working directory. File-access tools marked No still prompt for paths outside it. Bash runs a built-in set of read-only commands without asking. Example: [[tool.bash]].
term.settings-scope | term | VERIFIED | S3 | Settings scope | The file a setting lives in: user, shared project, project local, or managed. See [[setting-file.user]] and [[precedence.rule]].
term.artifact | term | VERIFIED | S6, S7 | Artifact | A claude.ai page built from HTML or Markdown. It can be watched, commented on, and given a shared database. See [[tool.artifact]].
term.remote-session | term | SESSION | S7 | Remote session | A session in a cloud environment or on another machine, driven by the claude-code-remote tools. See [[tool.remote-create-session]].
term.background-task | term | VERIFIED | S6 | Background task | A command or monitor that keeps running after the turn ends. See [[process.background-time-limit]].
term.workflow | term | VERIFIED | S6, S8 | Workflow | A rerunnable script that runs many subagents. Opt-in. See [[feature.workflows]].
term.compaction | term | VERIFIED | S2, S8 | Compaction | Summarizing older context when the window fills. Hooks: [[hook.pre-compact]] and [[hook.post-compact]]. Context budget: [[feature.context-window]].
term.plugin | term | INDEX | S1 | Plugin | A bundle of skills, hooks, MCP servers, agents and output styles. See [[plugin.overview]].
term.mod | term | INDEX | S1 | Mod | A plugin-style extension that can draw panes, add commands, and react to events. See [[mod.overview]].
hook.session-start | hook | VERIFIED | S2 | SessionStart | Fires when a session begins or resumes. Matchers: startup, resume, clear, compact, fork. Plain stdout is added to context. Handler types: command and mcp_tool only. Exit 2 shows stderr to the user only. Input: [[hook-rule.stdin-session-start]].
hook.setup | hook | VERIFIED | S2 | Setup | Fires for --init-only, and for --init or --maintenance with -p. Matchers: init, maintenance. Side effects only.
hook.session-end | hook | VERIFIED | S2 | SessionEnd | Fires when a session terminates. Matchers: clear, resume, logout, prompt_input_exit, other. Exit 2 shows stderr to the user only. Shares a 1.5 s budget, raised to match a longer per-hook timeout of up to 60 s ([[hook-rule.timeout-defaults]]).
hook.user-prompt-submit | hook | VERIFIED | S2 | UserPromptSubmit | Fires when a prompt is submitted, before processing, including turns Claude starts itself. No matcher. Exit 2 blocks the prompt. Plain stdout is added to context. Top-level decision block: [[hook-rule.output-top-level-block]].
hook.user-prompt-expansion | hook | VERIFIED | S2 | UserPromptExpansion | Fires when a user-typed command expands into a prompt. Matcher: command name. Exit 2 blocks the expansion.
hook.pre-tool-use | hook | VERIFIED | S2 | PreToolUse | Fires before a tool call runs. Matcher: tool name. Exit 2 blocks the call. Decisions: allow, deny, ask or defer ([[hook-rule.output-pre-tool-use]]). A timeout does not block. EndConversation calls skip it. The if field applies here: [[hook-rule.if-field]].
hook.permission-request | hook | VERIFIED | S2 | PermissionRequest | Fires when a tool call needs a permission decision. Matcher: tool name. Exit 2 is not honored; decide with decision.behavior ([[hook-rule.output-permission-request]]).
hook.permission-denied | hook | VERIFIED | S2 | PermissionDenied | Fires when auto mode denies a tool call. Matcher: tool name. Exit 2 is ignored. Output retry: true is ignored for denials without a classifier verdict.
hook.post-tool-use | hook | VERIFIED | S2 | PostToolUse | Fires after a tool call succeeds. Matcher: tool name. Exit 2 does not block; stderr goes to Claude. Top-level decision block and additionalContext apply. Can replace the tool result with updatedToolOutput.
hook.post-tool-use-failure | hook | VERIFIED | S2 | PostToolUseFailure | Fires after a tool call fails. Matcher: tool name. Exit 2 does not block; stderr goes to Claude.
hook.post-tool-batch | hook | VERIFIED | S2 | PostToolBatch | Fires after a parallel tool batch resolves, before the next model call. No matcher. Exit 2 stops the loop before the next model call. Top-level decision block applies.
hook.notification | hook | VERIFIED | S2 | Notification | Fires when Claude Code sends a notification. Thirteen matcher types, such as permission_prompt and idle_prompt. Side effects only.
hook.message-display | hook | VERIFIED | S2 | MessageDisplay | Fires when assistant message text is displayed. No matcher. Output displayContent changes the display only. Exit 2 shows the original text.
hook.subagent-start | hook | VERIFIED | S2 | SubagentStart | Fires when a subagent is spawned. Matcher: agent type, such as general-purpose, Explore, Plan, a custom name, or a plugin-scoped name. Output: additionalContext. Exit 2 shows stderr to the user only. See [[term.subagent]].
hook.subagent-stop | hook | VERIFIED | S2 | SubagentStop | Fires when a subagent finishes. Matcher: agent type. Exit 2 blocks, so the subagent keeps working. Input: [[hook-rule.stdin-stop]].
hook.task-created | hook | VERIFIED | S2 | TaskCreated | Fires when a task is created with TaskCreate ([[tool.task-create]]). No matcher. Exit 2 rolls the task back. A top-level decision block cancels it.
hook.task-completed | hook | VERIFIED | S2 | TaskCompleted | Fires when a task is marked completed. No matcher. Exit 2 means the task is not completed. Output: stopReason.
hook.teammate-idle | hook | VERIFIED | S2 | TeammateIdle | Fires when an agent-team teammate is about to go idle. Exit 2 keeps the teammate working. Output: stopReason. See [[feature.agent-teams]].
hook.stop | hook | VERIFIED | S2 | Stop | Fires when Claude finishes responding. No matcher. Exit 2 blocks, so Claude keeps working. Top-level decision block applies. Input: [[hook-rule.stdin-stop]].
hook.stop-failure | hook | VERIFIED | S2 | StopFailure | Fires when a turn ends because of an API error. Matchers: rate_limit, overloaded, authentication_failed, oauth_org_not_allowed, account_on_hold, billing_error, invalid_request, model_not_found, server_error, max_output_tokens, cloud_credential_error, unknown. Exit 2 is ignored, except for terminalSequence output.
hook.instructions-loaded | hook | VERIFIED | S2 | InstructionsLoaded | Fires when CLAUDE.md or .claude/rules/*.md enters context. Matchers: session_start, nested_traversal, path_glob_match, include, compact. Side effects only. See [[memory.claude-md]].
hook.config-change | hook | VERIFIED | S2 | ConfigChange | Fires when a config file changes during a session. Matchers: user_settings, project_settings, local_settings, policy_settings, skills. Exit 2 blocks the change, except for policy_settings.
hook.cwd-changed | hook | VERIFIED | S2 | CwdChanged | Fires when the working directory changes, for example after cd. No matcher. Side effects only; stderr goes to the user.
hook.directory-added | hook | VERIFIED | S2 | DirectoryAdded | Fires when a directory is added with /add-dir or the SDK register_repo_root. Matchers: slash_command, register_repo_root. Exit 2 goes to the debug log.
hook.file-changed | hook | VERIFIED | S2 | FileChanged | Fires when a watched file changes on disk. Matcher: literal filenames such as .envrc|.env, using letters, digits, underscore and pipe only. Side effects only.
hook.worktree-create | hook | VERIFIED | S2 | WorktreeCreate | Fires when a worktree is created by --worktree, isolation: worktree, or a background session. Replaces the default git behavior. Output: a path on stdout, or hookSpecificOutput.worktreePath over HTTP. Any non-zero exit fails creation. See [[feature.worktrees]].
hook.worktree-remove | hook | VERIFIED | S2 | WorktreeRemove | Fires when a worktree that a WorktreeCreate hook made is removed. Any non-zero exit fails the removal. JSON output is discarded.
hook.pre-compact | hook | VERIFIED | S2 | PreCompact | Fires before context compaction. Matchers: manual, auto. Exit 2 blocks compaction. See [[term.compaction]].
hook.post-compact | hook | VERIFIED | S2 | PostCompact | Fires after compaction completes. Matchers: manual, auto. Side effects only; stderr goes to the user.
hook.pre-model-switch | hook | VERIFIED | S2 | PreModelSwitch | Fires before a requested model switch applies. Matcher: canonical model name. Can block with exit 2, a permissionDecision of deny, or a top-level decision block. A timeout blocks the switch.
hook.post-model-switch | hook | VERIFIED | S2 | PostModelSwitch | Fires after the session's model changes, including automatic changes. Matcher: canonical model name. Plain stdout is added to context. Input: [[hook-rule.stdin-model-switch]].
hook.elicitation | hook | VERIFIED | S2 | Elicitation | Fires when an MCP server asks for user input during a tool call. Matcher: MCP server name. Output: action (accept, decline or cancel) and content. Exit 2 declines with no dialog. See [[mcp.overview]].
hook.elicitation-result | hook | VERIFIED | S2 | ElicitationResult | Fires after the user answers an MCP elicitation, before the reply goes back. Matcher: MCP server name. Exit 2 turns the reply into a decline.
