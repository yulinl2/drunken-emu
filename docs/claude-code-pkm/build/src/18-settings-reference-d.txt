# Settings reference, part D: MCP, agents, worktrees, remote control, login, updates, managed policy and global-config keys (windows 3 and 4).
setting.allowed-mcp-servers | setting | VERIFIED | S12 | allowedMcpServers | Scope: any file. Type: array of objects. Default: unset. Allowlists the MCP servers users can add; any server that matches no entry is blocked.
setting.allow-managed-mcp-servers-only | setting | VERIFIED | S12 | allowManagedMcpServersOnly | Scope: managed. Type: Boolean. Default: false. Reads allowedMcpServers from managed settings only, ignoring the user, project and local allowlists.
setting.denied-mcp-servers | setting | VERIFIED | S12 | deniedMcpServers | Scope: any file. Type: array of objects. Default: unset. Blocks matching MCP servers wherever they are defined; takes precedence over the allowlist.
setting.disable-claude-ai-connectors | setting | VERIFIED | S12 | disableClaudeAiConnectors | Scope: any file. Type: Boolean. Default: false. Turns off claude.ai MCP connectors, so Claude Code neither fetches nor connects them. A true value is honored from any scope; see setting.managed-exception.disable-claude-ai-connectors.
setting.disabled-mcpjson-servers | setting | VERIFIED | S12 | disabledMcpjsonServers | Scope: any file. Type: array of strings. Default: unset. Rejects the named .mcp.json servers so that Claude Code never connects to them or asks for approval.
setting.enable-all-project-mcp-servers | setting | VERIFIED | S12 | enableAllProjectMcpServers | Scope: any file. Type: Boolean. Default: unset. Approves every project .mcp.json server without a prompt.
setting.enabled-mcpjson-servers | setting | VERIFIED | S12 | enabledMcpjsonServers | Scope: any file. Type: array of strings. Default: unset. Approves the named project .mcp.json servers so that they connect without asking.
setting.managed-mcp-servers | setting | VERIFIED | S12 | managedMcpServers | Scope: managed. Type: object keyed by server name. Default: unset. Provides remote MCP servers to every user from managed settings.
setting.agent | setting | VERIFIED | S12 | agent | Scope: any file. Type: string. Default: unset. Runs the main thread as a named subagent, applying its prompt, tools and model.
setting.cross-session-inbound | setting | VERIFIED | S12 | crossSessionInbound | Scope: any file. Type: string. Default: unset. Chooses whether messages from other sessions are accepted, held or refused. A stricter value from a project or local file is honored; see setting.managed-exception.cross-session-inbound.
setting.disable-agent-view | setting | VERIFIED | S12 | disableAgentView | Scope: any file. Type: Boolean. Default: unset. Turns off background agents and agent view, including claude agents and --bg.
setting.isolate-peer-machines | setting | VERIFIED | S12 | isolatePeerMachines | Scope: any file. Type: Boolean. Default: unset. Requires approval before SendMessage reaches your sessions beyond this machine. A true value is honored from any scope; see setting.managed-exception.isolate-peer-machines.
setting.process-wrapper | setting | VERIFIED | S12 | processWrapper | Scope: user or managed. Type: string. Default: unset. Places a corporate launcher in front of background processes on macOS and Linux.
setting.teammate-mode | setting | VERIFIED | S12 | teammateMode | Scope: any file. Type: string. Default: "in-process". Chooses where agent team teammates appear, in-process or in split panes.
setting.worktree | setting | VERIFIED | S12 | worktree | Scope: any file. Type: object. Default: unset. Configures how Claude Code creates and manages git worktrees.
setting.worktree-base-ref | setting | VERIFIED | S12 | worktree.baseRef | Scope: any file. Type: string. Default: "fresh". Chooses whether new worktrees branch from origin's default branch or from the local HEAD.
setting.worktree-symlink-directories | setting | VERIFIED | S12 | worktree.symlinkDirectories | Scope: any file. Type: array of strings. Default: unset. Symlinks the listed repository directories into each worktree instead of duplicating them.
setting.worktree-sparse-paths | setting | VERIFIED | S12 | worktree.sparsePaths | Scope: any file. Type: array of strings. Default: unset. Checks out only the listed directories in each worktree through git sparse-checkout.
setting.worktree-bg-isolation | setting | VERIFIED | S12 | worktree.bgIsolation | Scope: any file. Type: string. Default: "worktree". Chooses whether background sessions edit in a worktree or in the working copy directly.
setting.worktree-location | setting | VERIFIED | S12 | worktree.location | Scope: user. Type: string. Default: unset. Folder on a remote machine where Desktop SSH sessions create their worktrees.
setting.agent-push-notif-enabled | setting | VERIFIED | S12 | agentPushNotifEnabled | Scope: any file. Type: Boolean. Default: false. Lets Claude send phone push notifications when it decides one is worth sending.
setting.away-summary-enabled | setting | VERIFIED | S12 | awaySummaryEnabled | Scope: any file. Type: Boolean. Default: unset (recap on). Shows a one-line session recap when you return after a few minutes away.
setting.disable-artifact | setting | VERIFIED | S12 | disableArtifact | Scope: any file. Type: Boolean. Default: unset. Deprecated; use enableArtifact instead to turn off the Artifact tool.
setting.disable-deep-link-registration | setting | VERIFIED | S12 | disableDeepLinkRegistration | Scope: any file. Type: string, "disable". Default: unset. Stops registering the claude-cli:// protocol handler with the operating system.
setting.disable-desktop-local-sessions | setting | VERIFIED | S12 | disableDesktopLocalSessions | Scope: managed. Type: Boolean. Default: unset. Turns off on-device Code sessions in the desktop app, for remote-only deployments.
setting.disable-remote-control | setting | VERIFIED | S12 | disableRemoteControl | Scope: any file. Type: Boolean. Default: false. Turns off Remote Control, including the --remote-control flag and auto-start.
setting.enable-artifact | setting | VERIFIED | S12 | enableArtifact | Scope: any file. Type: Boolean. Default: unset. Turns off the Artifact tool when false; no file can turn it back on.
setting.input-needed-notif-enabled | setting | VERIFIED | S12 | inputNeededNotifEnabled | Scope: any file. Type: Boolean. Default: false. Sends a phone notification when a permission prompt or question is waiting for input.
setting.preferred-notif-channel | setting | VERIFIED | S12 | preferredNotifChannel | Scope: any file. Type: string. Default: "auto". Chooses how Claude Code notifies you when a task completes or a prompt waits.
setting.remote-default-environment-id | setting | VERIFIED | S12 | remote.defaultEnvironmentId | Scope: any file. Type: string. Default: unset. Default cloud environment for cloud sessions created from the CLI.
setting.remote-control-at-startup | setting | VERIFIED | S12 | remoteControlAtStartup | Scope: any file. Type: Boolean. Default: unset. Connects Remote Control automatically when each interactive session starts. A false value in a project or local file is honored; see setting.managed-exception.remote-control-at-startup.
setting.ssh-configs | setting | VERIFIED | S12 | sshConfigs | Scope: user or managed. Type: array of objects. Default: unset. Adds SSH connections to the Desktop environment selector.
setting.ssh-host-allowlist | setting | VERIFIED | S12 | sshHostAllowlist | Scope: managed. Type: array of hostname patterns. Default: unset. Limits which hosts Desktop SSH sessions can reach; an empty array turns SSH off.
setting.allowed-providers | setting | VERIFIED | S12 | allowedProviders | Scope: managed. Type: array of strings. Default: unset. Lists the services a machine may reach Claude through; unlisted providers are refused.
setting.api-key-helper | setting | VERIFIED | S12 | apiKeyHelper | Scope: any file. Type: string. Default: unset. Runs your command to produce the credential Claude Code sends with model requests.
setting.aws-auth-refresh | setting | VERIFIED | S12 | awsAuthRefresh | Scope: any file. Type: string. Default: unset. Runs a command, such as aws sso login, when Bedrock credentials stop working.
setting.aws-credential-export | setting | VERIFIED | S12 | awsCredentialExport | Scope: any file. Type: string. Default: unset. Runs a command that prints AWS credentials as JSON for Bedrock.
setting.force-login-method | setting | VERIFIED | S12 | forceLoginMethod | Scope: any file. Type: string. Default: unset. Restricts login to claude.ai or Console accounts, or sends users to a cloud gateway.
setting.force-login-gateway-url | setting | VERIFIED | S12 | forceLoginGatewayUrl | Scope: user or managed. Type: string. Default: unset. Sets the gateway URL that the /login Cloud gateway screen connects to.
setting.force-login-org-uuid | setting | VERIFIED | S12 | forceLoginOrgUUID | Scope: any file. Type: string or array of strings. Default: unset. Limits claude.ai logins to the listed organization UUID or UUIDs.
setting.gateway-internal-networks | setting | VERIFIED | S12 | gatewayInternalNetworks | Scope: managed. Type: array of strings. Default: unset. Lists the public IPv4 blocks your internal network uses, so that /login accepts a gateway there.
setting.gcp-auth-refresh | setting | VERIFIED | S12 | gcpAuthRefresh | Scope: any file. Type: string. Default: unset. Runs a command that refreshes expired Google Cloud Application Default Credentials.
setting.otel-headers-helper | setting | VERIFIED | S12 | otelHeadersHelper | Scope: any file. Type: string. Default: unset. Runs a command that generates headers for OpenTelemetry exports, such as rotating tokens.
setting.auto-updates-channel | setting | VERIFIED | S12 | autoUpdatesChannel | Scope: any file. Type: string. Default: unset (latest). Chooses the release channel for auto-updates: "latest" or "stable".
setting.minimum-version | setting | VERIFIED | S12 | minimumVersion | Scope: any file. Type: string, version number. Default: unset. Stops auto-updates and claude update from installing versions below this one.
setting.required-maximum-version | setting | VERIFIED | S12 | requiredMaximumVersion | Scope: managed. Type: string, version number. Default: unset. Sets the newest Claude Code version your organization allows to start.
setting.required-minimum-version | setting | VERIFIED | S12 | requiredMinimumVersion | Scope: managed. Type: string, version number. Default: unset. Sets the oldest Claude Code version your organization allows to start.
setting.browser-external-page-tools | setting | VERIFIED | S12 | browserExternalPageTools | Scope: managed. Type: string, "disabled". Default: unset. Stops Claude's tools from reading or acting on external pages in the Browser pane.
setting.disable-browser-external-navigation | setting | VERIFIED | S12 | disableBrowserExternalNavigation | Scope: managed. Type: Boolean. Default: unset. Turns off external browsing in the desktop Browser pane, for people and for Claude.
setting.disable-mobile-simulator-tools | setting | VERIFIED | S12 | disableMobileSimulatorTools | Scope: managed. Type: Boolean. Default: unset. Blocks Claude's tools for the desktop app's iOS Simulator pane.
setting.cleanup-period-days | setting | VERIFIED | S12 | cleanupPeriodDays | Scope: any file. Type: number of days. Default: 30. Sets how many days Claude Code keeps session transcripts before deleting them.
setting.desktop-session-cleanup-period-days | setting | VERIFIED | S12 | desktopSessionCleanupPeriodDays | Scope: user or managed. Type: number of days. Default: 0. Age limit in days for Desktop and Cowork session transcripts; 0 sets no limit.
setting.feedback-drafts | setting | VERIFIED | S12 | feedbackDrafts | Scope: user or managed. Type: string. Default: "notify". Controls whether Claude queues feedback drafts and whether a card appears for them.
setting.feedback-survey-rate | setting | VERIFIED | S12 | feedbackSurveyRate | Scope: any file. Type: number from 0 to 1. Default: unset. Probability that the session quality survey appears when a session is eligible.
setting.skip-web-fetch-preflight | setting | VERIFIED | S12 | skipWebFetchPreflight | Scope: any file. Type: Boolean. Default: unset. Skips the WebFetch domain safety check that sends hostnames to Anthropic.
setting.disable-sideload-flags | setting | VERIFIED | S12 | disableSideloadFlags | Scope: managed. Type: Boolean. Default: false. Rejects the --plugin-dir, --plugin-url, --agents and --mcp-config flags at startup.
setting.force-remote-settings-refresh | setting | VERIFIED | S12 | forceRemoteSettingsRefresh | Scope: managed. Type: Boolean. Default: false. Blocks startup until server-managed settings are freshly fetched, and exits on failure.
setting.managed-sources-behavior | setting | VERIFIED | S12 | managedSourcesBehavior | Scope: managed. Type: string. Default: "first-wins". Chooses whether only the top managed source applies, or whether all admin sources merge.
setting.parent-settings-behavior | setting | VERIFIED | S12 | parentSettingsBehavior | Scope: managed. Type: string. Default: "first-wins". Chooses whether host-supplied managed settings are dropped or merged under admin policy.
setting.policy-helper | setting | VERIFIED | S12 | policyHelper | Scope: managed. Type: object. Default: unset. Runs a deployed executable at startup that computes managed settings.
setting.policy-helper-path | setting | VERIFIED | S12 | policyHelper.path | Scope: managed. Type: string. Default: none; required. Absolute path to the helper executable that Claude Code runs.
setting.policy-helper-timeout-ms | setting | VERIFIED | S12 | policyHelper.timeoutMs | Scope: managed. Type: integer, milliseconds. Default: 10000. How long Claude Code waits for the helper before treating the run as failed.
setting.policy-helper-refresh-interval-ms | setting | VERIFIED | S12 | policyHelper.refreshIntervalMs | Scope: managed. Type: integer, milliseconds. Default: unset. Interval for re-running the helper in the background, so that policy changes reach running sessions.
setting.wsl-inherits-windows-settings | setting | VERIFIED | S12 | wslInheritsWindowsSettings | Scope: managed. Type: Boolean. Default: false. Lets WSL read managed settings from the Windows policy chain.
setting.auto-connect-ide | setting | VERIFIED | S12 | autoConnectIde | Scope: global config (~/.claude.json). Type: Boolean. Default: false. Connects to a running IDE automatically when Claude Code starts from an external terminal.
setting.auto-install-ide-extension | setting | VERIFIED | S12 | autoInstallIdeExtension | Scope: global config (~/.claude.json). Type: Boolean. Default: true. Installs the IDE extension automatically when Claude Code runs from a VS Code terminal.
setting.claude-in-chrome-default-enabled | setting | VERIFIED | S12 | claudeInChromeDefaultEnabled | Scope: global config (~/.claude.json). Type: Boolean. Default: unset. Starts interactive sessions with Chrome integration on, without passing --chrome.
setting.copy-full-response | setting | VERIFIED | S12 | copyFullResponse | Scope: global config (~/.claude.json). Type: Boolean. Default: false. Makes /copy copy the full response without showing the picker.
setting.copy-on-select | setting | VERIFIED | S12 | copyOnSelect | Scope: global config (~/.claude.json). Type: Boolean. Default: true. Copies text to the clipboard when you finish selecting it with the mouse.
setting.default-to-agents-view | setting | VERIFIED | S12 | defaultToAgentsView | Scope: global config (~/.claude.json). Type: Boolean. Default: false. Opens agent view instead of a new conversation when claude runs with no arguments.
setting.diff-tool | setting | VERIFIED | S12 | diffTool | Scope: global config (~/.claude.json). Type: string. Default: "auto". Shows Edit and Write diffs in the IDE viewer or in the terminal.
setting.external-editor-context | setting | VERIFIED | S12 | externalEditorContext | Scope: global config (~/.claude.json); Claude Code ignores it in settings.json. Type: Boolean. Default: false. With true, the Ctrl+G editor buffer starts with Claude's previous response as # comment lines, which are stripped on save; with false it opens with only your prompt.
setting.left-arrow-opens-agents | setting | VERIFIED | S12 | leftArrowOpensAgents | Scope: global config (~/.claude.json); Claude Code ignores it in settings.json. Type: Boolean. Default: true. Pressing the left arrow on an empty prompt backgrounds the session and opens agent view; false turns the shortcut off.
setting.permission-explainer-enabled | setting | REMOVED | - | permissionExplainerEnabled | Scope: global config, through v2.1.256. Type: Boolean. Default: true. Removed in v2.1.257 together with the Ctrl+E command explanation on Bash and PowerShell permission prompts; setting it has no effect now.
setting.pr-status-footer-enabled | setting | VERIFIED | S12 | prStatusFooterEnabled | Scope: global config (~/.claude.json); Claude Code ignores it in settings.json. Type: Boolean. Default: true. Shows a badge in the prompt footer for the open pull request or merge request on the current branch.
setting.teammate-default-model | setting | REMOVED | - | teammateDefaultModel | Scope: global config, through v2.1.233. Type: string, a model alias or full model ID, or null. Default: unset. Removed in v2.1.234 together with the Default teammate model row in /config; setting it has no effect now.
