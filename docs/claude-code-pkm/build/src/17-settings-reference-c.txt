# Settings reference, part C: display, interface, attribution, hooks, skills and plugin keys (window 2).
setting.emoji-completion-enabled | setting | VERIFIED | S12 | emojiCompletionEnabled | Scope: any file. Type: Boolean. Default: true. Shows emoji suggestions for colon shortcodes and replaces completed ones with emoji.
setting.file-suggestion | setting | VERIFIED | S12 | fileSuggestion | Scope: any file. Type: object. Default: unset. Runs your own command to supply @ file path autocomplete.
setting.footer-links-regexes | setting | VERIFIED | S12 | footerLinksRegexes | Scope: user or managed. Type: array. Default: unset. Shows footer badges that link matched text to URLs when a regex matches turn output.
setting.keybinding-flavor | setting | VERIFIED | S12 | keybindingFlavor | Scope: any file. Type: string. Default: unset. Deprecated since v2.1.261 with no effect; word-editing keys follow readline.
setting.max-prose-width | setting | VERIFIED | S12 | maxProseWidth | Scope: any file. Type: number. Default: unset. Caps prose width in responses; tables and code keep the full terminal width.
setting.prefers-reduced-motion | setting | VERIFIED | S12 | prefersReducedMotion | Scope: any file. Type: Boolean. Default: false. Reduces or turns off spinner, shimmer and flash animations.
setting.prompt-suggestion-enabled | setting | VERIFIED | S12 | promptSuggestionEnabled | Scope: any file. Type: Boolean. Default: true. Shows or hides grayed-out predictions in the prompt input.
setting.respect-gitignore | setting | VERIFIED | S12 | respectGitignore | Scope: any file. Type: Boolean. Default: true. Whether the @ file picker leaves out files that match .gitignore patterns.
setting.respond-to-bash-commands | setting | VERIFIED | S12 | respondToBashCommands | Scope: any file. Type: Boolean. Default: true. Whether Claude replies after a !-prefixed shell command; false only adds the output to context.
setting.show-clear-context-on-plan-accept | setting | VERIFIED | S12 | showClearContextOnPlanAccept | Scope: any file. Type: Boolean. Default: false. Adds a clear-context option to the plan approval menu.
setting.show-turn-duration | setting | VERIFIED | S12 | showTurnDuration | Scope: any file. Type: Boolean. Default: true. Shows or hides the turn duration message after each response.
setting.spellcheck | setting | VERIFIED | S12 | spellcheck | Scope: user or managed. Type: object. Default: unset. Underlines misspelled words in the prompt input using an installed spell checker.
setting.spinner-tips-enabled | setting | VERIFIED | S12 | spinnerTipsEnabled | Scope: any file. Type: Boolean. Default: true. Shows or hides tips in the spinner while Claude works.
setting.spinner-tips-override | setting | VERIFIED | S12 | spinnerTipsOverride | Scope: any file. Type: object. Default: unset. Adds your own tips to the spinner rotation, or replaces the built-in tips.
setting.spinner-verbs | setting | VERIFIED | S12 | spinnerVerbs | Scope: any file. Type: object. Default: unset. Adds your own verbs to the spinner rotation, or replaces the built-in verbs.
setting.status-line | setting | VERIFIED | S12 | statusLine | Scope: any file. Type: object. Default: unset. Runs your command to render a status line below the prompt.
setting.subagent-status-line | setting | VERIFIED | S12 | subagentStatusLine | Scope: any file. Type: object. Default: unset. Runs your command to rewrite the subagent task rows below the prompt.
setting.syntax-highlighting-disabled | setting | VERIFIED | S12 | syntaxHighlightingDisabled | Scope: any file. Type: Boolean. Default: false. Shows diffs, code blocks and file previews as plain text when true.
setting.terminal-progress-bar-enabled | setting | VERIFIED | S12 | terminalProgressBarEnabled | Scope: any file. Type: Boolean. Default: true. Shows a busy indicator on the terminal tab or taskbar while Claude works.
setting.terminal-title-from-rename | setting | VERIFIED | S12 | terminalTitleFromRename | Scope: any file. Type: Boolean. Default: true. Shows your session name as the tab title; false keeps the generated title.
setting.theme | setting | VERIFIED | S12 | theme | Scope: any file. Type: string. Default: "dark". Sets the interface color theme, including colorblind-friendly and custom themes.
setting.time-format | setting | VERIFIED | S12 | timeFormat | Scope: any file. Type: string. Default: "auto". Sets how interface times are written: 12-hour, 24-hour, or a strftime pattern.
setting.time-zone | setting | VERIFIED | S12 | timeZone | Scope: any file. Type: string. Default: unset. Shows interface times in an IANA time zone instead of the system zone.
setting.tui | setting | VERIFIED | S12 | tui | Scope: any file. Type: string. Default: unset. Selects the classic main-screen or the flicker-free fullscreen terminal renderer.
setting.verbose | setting | VERIFIED | S12 | verbose | Scope: any file. Type: Boolean. Default: false. Shows full tool input and output inline instead of truncated summaries.
setting.vim-insert-mode-remaps | setting | VERIFIED | S12 | vimInsertModeRemaps | Scope: user or managed. Type: object. Default: unset. Maps two-key INSERT-mode sequences to Escape in vim editor mode.
setting.voice | setting | VERIFIED | S12 | voice | Scope: any file. Type: object. Default: unset. Turns on voice dictation and sets whether the key is held or tapped.
setting.voice-enabled | setting | VERIFIED | S12 | voiceEnabled | Scope: any file. Type: Boolean. Default: unset. Deprecated Boolean that turns on voice dictation; voice.enabled takes precedence.
setting.wheel-scroll-acceleration-enabled | setting | VERIFIED | S12 | wheelScrollAccelerationEnabled | Scope: any file. Type: Boolean. Default: true. Accelerates mouse-wheel scrolling during fast scrolls in fullscreen rendering.
setting.attribution | setting | VERIFIED | S12 | attribution | Scope: any file. Type: object, or false. Default: unset. Sets the commit trailer, the pull request text and the session link; false hides all attribution.
setting.include-co-authored-by | setting | VERIFIED | S12 | includeCoAuthoredBy | Scope: any file. Type: Boolean. Default: true. Deprecated; false omits the commit trailer and PR attribution unless attribution is set.
setting.include-git-instructions | setting | VERIFIED | S12 | includeGitInstructions | Scope: any file. Type: Boolean. Default: true. Includes the built-in git workflow instructions and a git status snapshot in context.
setting.pr-url-template | setting | VERIFIED | S12 | prUrlTemplate | Scope: any file. Type: string. Default: unset. Points rendered PR links at an internal review tool instead of github.com.
setting.attribution-commit | setting | VERIFIED | S12 | attribution.commit | Scope: any file. Type: string. Default: unset. Sets the commit attribution text; an empty string hides commit attribution.
setting.attribution-pr | setting | VERIFIED | S12 | attribution.pr | Scope: any file. Type: string. Default: unset. Sets the pull request attribution text; an empty string hides it.
setting.attribution-session-url | setting | VERIFIED | S12 | attribution.sessionUrl | Scope: any file. Type: Boolean. Default: true. Whether commits and PRs from cloud or Remote Control sessions include the session link.
setting.allowed-http-hook-urls | setting | VERIFIED | S12 | allowedHttpHookUrls | Scope: any file. Type: array. Default: unset. Limits which URLs HTTP hooks can target; an empty array blocks every HTTP hook.
setting.allow-managed-hooks-only | setting | VERIFIED | S12 | allowManagedHooksOnly | Scope: managed. Type: Boolean. Default: unset. When true, only managed, SDK and force-enabled plugin hooks run.
setting.disable-all-hooks | setting | VERIFIED | S12 | disableAllHooks | Scope: any file. Type: Boolean. Default: unset. Turns off hooks, any custom status line and any custom file suggestion command.
setting.disable-workflows | setting | VERIFIED | S12 | disableWorkflows | Scope: any file. Type: Boolean. Default: false. Turns off dynamic workflows and bundled workflow commands for everyone your settings reach.
setting.enable-workflows | setting | VERIFIED | S12 | enableWorkflows | Scope: any file. Type: Boolean. Default: unset. Turns dynamic workflows on or off for you, overriding your plan's default.
setting.hooks | setting | VERIFIED | S12 | hooks | Scope: any file. Type: object. Default: unset. Runs commands, prompts, agents, HTTP requests or MCP tools at lifecycle events. See hook.session-start for the event names.
setting.http-hook-allowed-env-vars | setting | VERIFIED | S12 | httpHookAllowedEnvVars | Scope: any file. Type: array. Default: unset. Limits which environment variables HTTP hooks can put into request headers.
setting.workflow-keyword-trigger-enabled | setting | VERIFIED | S12 | workflowKeywordTriggerEnabled | Scope: any file. Type: Boolean. Default: true. Whether typing the keyword ultracode in a prompt triggers a dynamic workflow.
setting.workflow-size-guideline | setting | VERIFIED | S12 | workflowSizeGuideline | Scope: any file. Type: string. Default: "medium" (small on Pro). Sets the agent count Claude aims for in dynamic workflows, as advice only.
setting.disable-bundled-skills | setting | VERIFIED | S12 | disableBundledSkills | Scope: any file. Type: Boolean. Default: unset. Turns off bundled skills and workflows and hides built-in commands from the model.
setting.disable-skill-shell-execution | setting | VERIFIED | S12 | disableSkillShellExecution | Scope: any file. Type: Boolean. Default: unset. Replaces inline shell commands in skills and custom commands with a policy notice.
setting.skill-overrides | setting | VERIFIED | S12 | skillOverrides | Scope: any file. Type: object. Default: unset. Hides or collapses individual skills without editing their SKILL.md files.
setting.sync-claude-ai-skills | setting | VERIFIED | S12 | syncClaudeAiSkills | Scope: user, local or managed. Type: Boolean. Default: unset. False stops downloading and loading skills synced from your claude.ai account.
setting.sync-claude-ai-plugins | setting | VERIFIED | S12 | syncClaudeAiPlugins | Scope: user, local or managed. Type: Boolean. Default: unset. False stops downloading and loading plugins synced from your claude.ai account.
setting.allowed-channel-plugins | setting | VERIFIED | S12 | allowedChannelPlugins | Scope: managed. Type: array. Default: unset. Sets which channel plugins may push messages into sessions; an empty array blocks all of them.
setting.blocked-marketplaces | setting | VERIFIED | S12 | blockedMarketplaces | Scope: managed. Type: array. Default: unset. Blocks plugin marketplace sources for your organization, checked before any download.
setting.channels-enabled | setting | VERIFIED | S12 | channelsEnabled | Scope: managed. Type: Boolean. Default: unset (plan-dependent). Allows channels for your organization; Team and Enterprise plans must set it to true.
setting.disable-command-plugin-sources | setting | VERIFIED | S12 | disableCommandPluginSources | Scope: managed. Type: Boolean. Default: unset. Blocks command-sourced plugins, which run marketplace-declared commands on the machine.
setting.plugin-suggestion-marketplaces | setting | VERIFIED | S12 | pluginSuggestionMarketplaces | Scope: managed. Type: array. Default: unset. Names marketplaces whose plugins can appear as contextual install suggestions.
setting.plugin-trust-message | setting | VERIFIED | S12 | pluginTrustMessage | Scope: managed. Type: string. Default: unset. Adds your organization's own text to the plugin trust warning.
setting.strict-known-marketplaces | setting | VERIFIED | S12 | strictKnownMarketplaces | Scope: managed. Type: array. Default: unset. Restricts which marketplace sources users can add and install plugins from.
setting.strict-plugin-only-customization | setting | VERIFIED | S12 | strictPluginOnlyCustomization | Scope: managed. Type: true, or an array of the four sub-keys. Default: unset. Limits skills, agents, hooks and MCP servers to plugins or managed settings.
setting.strict-plugin-only-customization-skills | setting | VERIFIED | S12 | strictPluginOnlyCustomization.skills | Scope: managed. Type: string in an array. Default: not locked. Blocks user and project skills and commands; plugin and bundled skills still load.
setting.strict-plugin-only-customization-agents | setting | VERIFIED | S12 | strictPluginOnlyCustomization.agents | Scope: managed. Type: string in an array. Default: not locked. Blocks user, project and added-directory agents; plugin and built-in agents still load.
setting.strict-plugin-only-customization-hooks | setting | VERIFIED | S12 | strictPluginOnlyCustomization.hooks | Scope: managed. Type: string in an array. Default: not locked. Stops user, project and local hooks; plugin and managed hooks keep running.
setting.strict-plugin-only-customization-mcp | setting | VERIFIED | S12 | strictPluginOnlyCustomization.mcp | Scope: managed. Type: string in an array. Default: not locked. Stops MCP servers defined in ~/.claude.json and .mcp.json; plugin and managed servers still load.
setting.enabled-plugins | setting | VERIFIED | S12 | enabledPlugins | Scope: any file. Type: object. Default: unset. Turns individual plugins on or off, keyed by plugin-name@marketplace-name.
setting.extra-known-marketplaces | setting | VERIFIED | S12 | extraKnownMarketplaces | Scope: any file. Type: object. Default: unset. Registers plugin marketplaces by name so that users get them without adding them.
setting.plugin-configs | setting | VERIFIED | S12 | pluginConfigs | Scope: user or managed. Type: object. Default: unset. Stores non-sensitive answers to a plugin's user configuration dialog, keyed by plugin ID.
setting.prepend-plugins | setting | VERIFIED | S12 | prependPlugins | Scope: user or managed. Type: array. Default: unset. Lists managed plugins whose mods run before every user-installed mod.
setting.append-plugins | setting | VERIFIED | S12 | appendPlugins | Scope: user or managed. Type: array. Default: unset. Lists managed plugins whose mods run after every user-installed mod.
setting.allow-all-claude-ai-mcps | setting | VERIFIED | S12 | allowAllClaudeAiMcps | Scope: managed. Type: Boolean. Default: false. Loads claude.ai connectors alongside a deployed managed-mcp.json instead of suppressing them.
setting.allow-claude-in-chrome-with-managed-mcp | setting | VERIFIED | S12 | allowClaudeInChromeWithManagedMcp | Scope: managed. Type: Boolean. Default: false. Lets the built-in Claude in Chrome server run alongside a deployed managed-mcp.json.
