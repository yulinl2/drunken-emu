# Environment variables (kind env), plugins, mods, MCP, features (INDEX unless marked), agent types (kind agent-type).
env.claude-project-dir | env | VERIFIED | S2 | CLAUDE_PROJECT_DIR | Project root where the session started. Available to command hooks, to stdio MCP servers and to plugin LSP servers. It does not move into a worktree; use cwd for the current directory. Not set in the Bash tool here ([[obs.claude-project-dir-unset-in-bash]]).
env.claude-plugin-root | env | VERIFIED | S2 | CLAUDE_PLUGIN_ROOT | Plugin installation directory, for command hooks. Substituted into command and exported to the process.
env.claude-plugin-data | env | VERIFIED | S2 | CLAUDE_PLUGIN_DATA | Plugin persistent data directory, for command hooks.
env.claude-plugin-option | env | VERIFIED | S2 | CLAUDE_PLUGIN_OPTION_<KEY> | A plugin's user-config value, for example CLAUDE_PLUGIN_OPTION_WEBHOOK_URL. Read it from exec-form or shell-form plugin hooks.
env.claude-env-file | env | VERIFIED | S2, S6 | CLAUDE_ENV_FILE | A file path. In SessionStart hooks, export lines appended to it apply to later Bash commands. Set it before launch to make variables persist across Bash commands ([[tool.bash]]).
env.claude-effort | env | VERIFIED | S2 | CLAUDE_EFFORT | The current effort level, available to hook commands and to the Bash tool.
env.claude-code-remote | env | VERIFIED | S2 | CLAUDE_CODE_REMOTE | "true" in remote web environments; unset in the local CLI.
env.claude-code-bridge-session-id | env | VERIFIED | S2 | CLAUDE_CODE_BRIDGE_SESSION_ID | The Remote Control session ID while connected (v2.1.199 or later).
env.claude-code-subprocess-env-scrub | env | VERIFIED | S2 | CLAUDE_CODE_SUBPROCESS_ENV_SCRUB | Set to 1 to scrub more environment variables from hook processes. By default, OTEL exporter variables are removed.
env.bash-default-timeout-ms | env | VERIFIED | S6 | BASH_DEFAULT_TIMEOUT_MS | The default timeout when Claude passes none; 2 minutes out of the box. Above 1,800,000 ms it also replaces the 30-minute background default.
env.bash-max-timeout-ms | env | VERIFIED | S6 | BASH_MAX_TIMEOUT_MS | The ceiling on requested timeouts; 10 minutes out of the box. Above 7,200,000 ms it also raises the 2-hour background cap.
env.bash-max-output-length | env | VERIFIED | S6 | BASH_MAX_OUTPUT_LENGTH | Characters read back from a command's output file: 30,000 by default, with a hard ceiling of 150,000. Replaced by the bashOutputMaxChars setting, which ignores it ([[setting.bash-output-max-chars]]).
env.claude-code-tool-memory-limit | env | VERIFIED | S6 | CLAUDE_CODE_TOOL_MEMORY_LIMIT | On Linux and WSL, caps the memory that Bash, PowerShell and Monitor commands share, for example 4G (v2.1.233 or later).
env.claude-code-tool-memory-cgroup-exclude | env | VERIFIED | S6 | CLAUDE_CODE_TOOL_MEMORY_CGROUP_EXCLUDE | A list of process kinds exempt from the memory cap: mcp, lsp, hooks, plugin, helper and agent. none caps every kind; all-new caps only the Bash, PowerShell and Monitor commands (v2.1.246 or later).
env.claude-code-disable-background-tasks | env | VERIFIED | S6 | CLAUDE_CODE_DISABLE_BACKGROUND_TASKS | Set to 1 to disable auto-backgrounding and background task functionality. A command that reaches its timeout then stops.
env.claude-bash-maintain-project-working-dir | env | VERIFIED | S6 | CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR | Set to 1 so every Bash command starts in the project directory, with no cd carry-over.
env.claude-code-glob-no-ignore | env | VERIFIED | S6 | CLAUDE_CODE_GLOB_NO_IGNORE | Set to false before launch to make Glob respect .gitignore ([[tool.glob]]).
env.claude-code-enable-tasks | env | VERIFIED | S6 | CLAUDE_CODE_ENABLE_TASKS | Set to 0 to re-enable TodoWrite in sessions that have the task-tracking tools, as worded in the tools reference ([[tool.todo-write]]).
env.claude-code-use-powershell-tool | env | VERIFIED | S6 | CLAUDE_CODE_USE_POWERSHELL_TOOL | 1 enables the PowerShell tool on Bedrock, Agent Platform and Foundry, and 0 turns it off on Windows. Required on Linux, macOS and WSL, which also need pwsh 7 or later ([[tool.powershell]]).
env.claude-code-powershell-respect-execution-policy | env | VERIFIED | S6 | CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY | Set to 1 to respect the machine's effective execution policy, instead of the process-scope bypass Claude Code uses by default.
env.claude-config-dir | env | VERIFIED | S3 | CLAUDE_CONFIG_DIR | Moves the home config folder, where settings, session history and plugins are stored. See [[setting-file.global-config]].
env.mcp-timeout | env | VERIFIED | S4, S6 | MCP_TIMEOUT | The MCP startup timeout, 30 seconds by default. Used by [[flag.mcp-config]] and [[flag.permission-prompt-tool]] when they wait for servers.
env.claude-ax-screen-reader | env | VERIFIED | S4 | CLAUDE_AX_SCREEN_READER | Screen-reader output. The --ax-screen-reader flag takes precedence over it ([[flag.ax-screen-reader]]).
env.claude-code-simple | env | VERIFIED | S4 | CLAUDE_CODE_SIMPLE | Set by --bare. Loads only shell and file tools ([[flag.bare]]).
env.claude-code-safe-mode | env | VERIFIED | S4 | CLAUDE_CODE_SAFE_MODE | Set by --safe-mode ([[flag.safe-mode]]).
env.claude-code-disable-nonessential-traffic | env | VERIFIED | S6 | CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC | When set, the Monitor tool is not available ([[tool.monitor]]).
env.disable-telemetry | env | VERIFIED | S6 | DISABLE_TELEMETRY | When set, the Monitor tool is not available ([[tool.monitor]]).
env.anthropic-model | env | VERIFIED | S2, S3 | ANTHROPIC_MODEL | A shell variable that overrides the model setting. It reflects the shell, not /model changes. See [[precedence.env-not-a-level]].
env.claude-code-skip-prompt-history | env | VERIFIED | S4 | CLAUDE_CODE_SKIP_PROMPT_HISTORY | Same effect as [[flag.no-session-persistence]], in any mode.
env.claude-code-provider-managed-by-host | env | VERIFIED | S3 | CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST | Set by an app that runs Claude Code inside itself. Its model configuration takes over the model keys from every managed source.
env.claude-remote-control-session-name-prefix | env | VERIFIED | S4 | CLAUDE_REMOTE_CONTROL_SESSION_NAME_PREFIX | Same effect as [[flag.remote-control-session-name-prefix]].
