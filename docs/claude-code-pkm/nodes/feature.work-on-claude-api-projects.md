# Work on Claude API projects

**Sources:** [S32](src.s32.md)

The bundled `/claude-api` skill loads Claude API and Managed Agents reference material for your project's language. Claude also activates it automatically when your code imports `anthropic` or `@anthropic-ai/sdk`.
