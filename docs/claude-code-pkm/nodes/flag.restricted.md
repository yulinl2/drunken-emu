# --restricted

**Sources:** [S4](src.s4.md)

Restricted mode for evaluation harnesses: removes command-running tools, confines file tools, loads only managed settings and --settings, refuses bypassPermissions and refuses to create cloud sessions (v2.1.248 or later).
