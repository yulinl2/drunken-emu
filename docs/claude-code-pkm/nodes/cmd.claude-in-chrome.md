# /claude-in-chrome

**Sources:** [S80](src.s80.md)

Skill. Have Claude carry out a task in your browser, such as testing a page, filling a form, or reading console logs, through Claude in Chrome. Available when Chrome integration is enabled for the session, for example with `claude --chrome`, or when Claude Code can offer to install the extension
