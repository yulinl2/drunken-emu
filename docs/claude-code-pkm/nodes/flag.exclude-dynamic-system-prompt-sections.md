# --exclude-dynamic-system-prompt-sections

**Sources:** [S4](src.s4.md)

Moves per-user context, such as the auto-memory location, into the first user message, for better cache reuse across users. See [Dynamic system-prompt sections](memory.dynamic-prompt-sections.md).
