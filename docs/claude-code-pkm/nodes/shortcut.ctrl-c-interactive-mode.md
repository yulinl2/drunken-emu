# Ctrl+C

**Sources:** [S83](src.s83.md)

Interrupt, or clear input (context: Interrupts a running operation. If nothing is running, the first press clears the prompt input and a second press exits Claude Code. To get a cleared draft back, see Bring back a cleared draft)
