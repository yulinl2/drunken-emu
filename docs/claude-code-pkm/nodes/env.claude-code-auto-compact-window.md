# CLAUDE_CODE_AUTO_COMPACT_WINDOW

**Sources:** [S81](src.s81.md)

Set the auto-compact window, how full the context gets before compaction, from `100000` to `1000000` tokens. Suffixed values such as `200k` require v2.1.304 or later. For precedence over the other ways to set the window and the effect on the status line's `used_percentage`, see Set the auto-compact window
