# Allow only pre-approved tools with dontAsk mode

**Sources:** [S67](src.s67.md)

If you set `dontAsk` mode, Claude Code auto-denies every tool call that would otherwise prompt you, though a mod you installed can still approve some of those calls. To check which calls a mod can approve, see Extend permissions with hooks.
