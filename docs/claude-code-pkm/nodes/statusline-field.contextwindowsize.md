# contextWindowSize

**Sources:** [S78](src.s78.md)

Context window of `model` in tokens, computed the same way as the main status line's `context_window.context_window_size`, so you can render a per-row percentage from `tokenCount`. Omitted when `model` is (type: number, optional)
