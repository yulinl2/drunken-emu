# autoMode

**Sources:** [S12](src.s12.md)

Scope: user or managed. Type: object with environment, allow, soft_deny and hard_deny arrays, plus classifyAllShell. Default: unset (built-in rules only). Adds your own rules to what the auto mode classifier blocks and allows.
