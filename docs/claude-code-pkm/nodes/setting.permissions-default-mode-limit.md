# permissions.defaultMode limit

**Sources:** [S3](src.s3.md)

The values auto and bypassPermissions do not take effect from project or local files. Before v2.1.257, bypassPermissions took effect from any file. See [Permission mode: auto](permission-mode.auto.md) and [Permission mode: bypassPermissions](permission-mode.bypass-permissions.md).
