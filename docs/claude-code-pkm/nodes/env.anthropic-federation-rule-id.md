# ANTHROPIC_FEDERATION_RULE_ID

**Sources:** [S81](src.s81.md)

Federation rule ID for Workload Identity Federation. When you set it together with `ANTHROPIC_ORGANIZATION_ID`, Claude Code selects federation credentials, which rank above your `/login` credential. See authentication precedence
