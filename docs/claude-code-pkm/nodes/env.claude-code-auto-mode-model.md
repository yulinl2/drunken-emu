# CLAUDE_CODE_AUTO_MODE_MODEL

**Sources:** [S81](src.s81.md)

Sets the model for the classifier requests Claude Code sends in auto mode. Use a full model ID such as `claude-sonnet-4-6`. For the cases where Claude Code ignores it, see Choose the classifier model. Requires Claude Code v2.1.302 or later
