# questions

**Sources:** [S85](src.s85.md)

Questions to present, each with a `question` string, short `header`, `options` array, and optional `multiSelect` flag (type: array; example: `[{"question": "Which framework?", "header": "Framework", "options": [{"label": "React", "description": "Component library"}, {"label": "Vue", "description": "Progressive framework"}], "multiSelect": false}]`)
