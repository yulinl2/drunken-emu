# PushNotification

**Sources:** [S82](src.s82.md)

Sends a desktop notification, and a phone push when Remote Control is connected, so a long-running task or session-scoped scheduled task can reach you when you step away. Push delivery runs through Anthropic-hosted infrastructure, which is not accessible from Amazon Bedrock, Claude Platform on AWS, Google Cloud's Agent Platform, or Microsoft Foundry (permission required: No)
