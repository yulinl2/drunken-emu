# Managed settings

**Sources:** [S66](src.s66.md)

For organizations that need centralized control, administrators deploy managed settings that user and project settings can't override, apart from a few security-sensitive keys. Deploy managed settings covers the delivery mechanisms, precedence within the managed tier, and the keys that only managed settings can set.
