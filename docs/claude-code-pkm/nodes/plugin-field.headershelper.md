# headersHelper

**Sources:** [S51](src.s51.md)

Command that prints this entry's archive-download headers as one JSON object, for a credential that expires. The entry must also set `"strict": false`. Requires Claude Code v2.1.238 or later. See Authenticate archive downloads (type: string)
