# CLAUDE_CODE_ARTIFACT_PUBLISH_EDITS

**Sources:** [S81](src.s81.md)

Set to `0` to stop Claude from applying small changes to an artifact's file as part of publishing it. Claude then edits the file with its file-editing tools and publishes it as a separate step. Requires Claude Code v2.1.300 or later
