# Choose how much to allow

**Sources:** [S58](src.s58.md)

Mod policies range from no installed mods at all to any mod a user chooses, with your own mod checking the others, and each one is a few managed settings. Find the policy you want in the first column and set what the second column names. Deploy managed settings covers where managed settings live.
