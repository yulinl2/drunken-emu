# Accumulating many images

**Sources:** [S18](src.s18.md)

The API limits how many images and PDFs each request can carry. For the current numbers, see Request limits in the API docs. Claude Code also caps the total size of the images and PDFs in a request, so large screenshots reach the limit with fewer images than small ones.
