# DISABLE_INSTALL_GITHUB_APP_COMMAND

**Sources:** [S81](src.s81.md)

Set to `1` to hide the `/install-github-app` command. Already hidden when using third-party providers (Amazon Bedrock, Google Cloud's Agent Platform, or Microsoft Foundry)
