# SubagentStart

**Sources:** [S2](src.s2.md)

Fires when a subagent is spawned. Matcher: agent type, such as general-purpose, Explore, Plan, a custom name, or a plugin-scoped name. Output: additionalContext. Exit 2 shows stderr to the user only. See [Subagent](term.subagent.md).
