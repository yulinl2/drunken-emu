# allowManagedMcpServersOnly

**Sources:** [S61](src.s61.md)

When `true`, only `allowedMcpServers` from managed settings are respected. `deniedMcpServers` still merges from all sources. See Keys read from every admin source for which managed sources can set it, and Managed MCP configuration
