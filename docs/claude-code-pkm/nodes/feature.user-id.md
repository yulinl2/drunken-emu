# user.id

**Sources:** [S65](src.s65.md)

Random anonymous identifier generated on first run and persisted in `~/.claude.json`. It contains no personal information and is not derived from your Claude account. Deleting the file produces a new unrelated value on next run. (controlled by: Always included)
