# Grep tool behavior

**Sources:** [S82](src.s82.md)

The Grep tool searches file contents for patterns. Where Glob finds files by name, Grep finds lines inside them. On macOS, Linux, and WSL, Grep is absent by default under the same conditions as Glob. See Glob tool behavior for when both tools are available.
