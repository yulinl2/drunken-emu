# CLAUDE_CODE_ARTIFACT_COMMENTS

**Sources:** [S81](src.s81.md)

Set to `0` to stop Claude reading and replying to comments on an artifact. Has no effect when `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` has turned artifacts off. Requires Claude Code v2.1.221 or later
