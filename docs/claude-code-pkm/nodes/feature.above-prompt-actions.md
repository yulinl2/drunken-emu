# Above-prompt actions

**Sources:** [S79](src.s79.md)

Actions for the band above the prompt, the shared strip where mods draw buttons, input fields, and selects. `abovePrompt:toggle` and `abovePrompt:focus` apply in the `Chat` context. The other actions apply in the context of whatever has keyboard focus in the band or a pane.
