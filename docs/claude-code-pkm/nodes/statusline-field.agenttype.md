# agentType

**Sources:** [S78](src.s78.md)

Subagent type the task runs as, such as the built-in `Explore` or a custom `code-reviewer`. Holds the same value that hooks receive as `agent_type`. Requires Claude Code v2.1.293 or later (type: string)
