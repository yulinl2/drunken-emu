# Connectors and plugin servers

**Sources:** [S11](src.s11.md)

Harness notices distinguish claude.ai connectors, which are signed in through connector settings, from other servers, which cannot be signed in from the session. Names are not recorded here ([Q15 (concern): Connection state is volatile.](question.q15.md)).
