# Edit rules from /permissions

**Sources:** [S64](src.s64.md)

To view and edit classifier rules and `environment` entries without opening a settings file, run `/permissions` and select the Auto mode tab. The tab requires Claude Code v2.1.246 or later, and it appears only when auto mode is available to your session.
