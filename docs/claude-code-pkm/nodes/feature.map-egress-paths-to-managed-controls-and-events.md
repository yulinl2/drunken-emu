# Map egress paths to managed controls and events

**Sources:** [S65](src.s65.md)

The table pairs paths that can carry session content off a machine, plus local retention, with the managed settings keys that restrict them and the events that record them. For what Claude Code itself sends to Anthropic, such as `/feedback` reports, see Data usage. The names link to their reference entries, which give the values and defaults.
