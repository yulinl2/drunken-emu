# prependPlugins, appendPlugins

**Sources:** [S54](src.s54.md)

Lists of plugin ids, such as `acme-guard@acme-tools`. Mods in `prependPlugins` run before every mod a user installs, and mods in `appendPlugins` run after, in the listed order. See The order mods run in. (where: Managed settings. User settings only on a machine with no managed settings, in a session whose credential isn't a Team or Enterprise `/login`.)
