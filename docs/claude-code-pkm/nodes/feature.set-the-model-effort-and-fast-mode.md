# Set the model, effort, and fast mode

**Sources:** [S26](src.s26.md)

In agent view, type `/model`, `/effort`, or `/fast` in the dispatch input and press `Enter`, and the sessions you dispatch afterward start with what you set. Your choice stays with that agent view window and isn't saved to a settings file. `/effort` and `/fast` require Claude Code v2.1.299 or later, as does `/model` typed with nothing after it.
