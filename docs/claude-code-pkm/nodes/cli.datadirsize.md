# dataDirSize

**Sources:** [S52](src.s52.md)

With `--data-size`, the size of the plugin's saved data directory as `bytes` and `human`; absent when the directory is missing or empty. Marketplace installs only. Requires Claude Code v2.1.285 or later (type: object)
