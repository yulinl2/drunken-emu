# "No eval cases found"

**Sources:** [S47](src.s47.md)

No `/prompt.md` or `/case.yaml` exists beneath the eval directory in effect, or your `--case` and `--tag` filters matched no case. Run from the plugin root, or run `claude plugin eval init` to create a suite.
