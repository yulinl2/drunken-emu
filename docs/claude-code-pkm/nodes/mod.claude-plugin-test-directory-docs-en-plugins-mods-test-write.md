# [claude plugin test [directory]](/docs/en/plugins/mods/test#write-a-test)

**Sources:** [S54](src.s54.md)

Runs every file under the directory, or the current directory when you give none, whose name ends in `.test.ts` or `.test.tsx`. Exits with status 1 when a test fails.
