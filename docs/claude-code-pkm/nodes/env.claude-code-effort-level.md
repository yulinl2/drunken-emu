# CLAUDE_CODE_EFFORT_LEVEL

**Sources:** [S81](src.s81.md)

Set the effort level for supported models. Values: `low`, `medium`, `high`, `xhigh`, `max`, or `auto` to use the model default. Available levels depend on the model. Takes precedence over `--effort`, `/effort`, and the `modelSettings` and `effortLevel` settings. A `maxEffortLevel` cap still applies. See Adjust effort level
