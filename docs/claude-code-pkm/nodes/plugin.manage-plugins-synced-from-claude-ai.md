# Manage plugins synced from claude.ai

**Sources:** [S42](src.s42.md)

The Installed tab in `/plugin` also lists the plugins synced from your claude.ai account, with `synced` as their source. Synced plugins appear in terminal sessions on Claude Code v2.1.273 or later.
