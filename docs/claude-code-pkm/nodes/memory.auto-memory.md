# Auto memory

**Sources:** [S1](src.s1.md), [S4](src.s4.md)

Claude keeps notes automatically across sessions, according to the memory page index. The auto-memory location is per-user context that [--exclude-dynamic-system-prompt-sections](flag.exclude-dynamic-system-prompt-sections.md) moves out of the system prompt.
