# claude ultrareview [target]

**Sources:** [S4](src.s4.md)

Runs ultrareview without a session. Prints findings and exits 0 or 1. Options: --json, --timeout (45 minutes by default) and --post. See [Ultrareview](feature.ultrareview.md).
