# File in a subdirectory of .claude/commands/

**Sources:** [S32](src.s32.md)

command name source: Subdirectory path relative to `commands/` with each `/` replaced by `:`, then the file name without extension; example: `.claude/commands/frontend/component.md` → `/frontend:component`
