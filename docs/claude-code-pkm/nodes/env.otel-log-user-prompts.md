# OTEL_LOG_USER_PROMPTS

**Sources:** [S81](src.s81.md)

Set to `1` to include user prompt text in OpenTelemetry traces and logs. Disabled by default (prompts are redacted). Set it in your shell, user settings, or managed settings. Ignored in project and local settings, apart from the off values that section describes. See Monitoring
