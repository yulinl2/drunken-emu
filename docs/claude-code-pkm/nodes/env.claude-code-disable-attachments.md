# CLAUDE_CODE_DISABLE_ATTACHMENTS

**Sources:** [S81](src.s81.md)

Set to `1` to disable attachment processing. File mentions with `@` syntax are sent as plain text instead of being expanded into file content. Ignored in project and local settings
