# disableClaudeAiConnectors

**Sources:** [S12](src.s12.md)

Scope: any file. Type: Boolean. Default: false. Turns off claude.ai MCP connectors, so Claude Code neither fetches nor connects them. A true value is honored from any scope; see setting.managed-exception.disable-claude-ai-connectors.
