# source

**Sources:** [S65](src.s65.md)

For an `accept` or `reject`, where the decision came from, such as `config`, `hook`, or `user_temporary`, with the meanings given under the Tool decision event. For a `cancelled`, what ended the wait before any decision was made, such as `user_abort`
