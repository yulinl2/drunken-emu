# false

**Sources:** [S31](src.s31.md)

The tool stays deferred when their configuration sets `"alwaysLoad": true`. This applies when your server is passed with `--mcp-config`, supplied by an Agent SDK application, or provided by a plugin. On other servers the tool loads upfront. Requires Claude Code v2.1.285 or later
