# ANTHROPIC_DEFAULT_HAIKU_MODEL_NAME

**Sources:** [S81](src.s81.md)

Display name for the pinned Haiku model in the `/model` picker. When not set, the row shows the model's name if Claude Code recognizes the pinned ID, and the pinned ID otherwise. See Model configuration
