# permissionMode

**Sources:** [S25](src.s25.md)

Permission mode: `default`, `acceptEdits`, `auto`, `dontAsk`, `bypassPermissions`, `plan`, or `manual` as an alias for `default`. Ignored for plugin subagents (required: No)
