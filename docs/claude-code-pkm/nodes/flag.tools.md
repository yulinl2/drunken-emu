# --tools

**Sources:** [S4](src.s4.md)

Restricts the built-in tools. An empty string disables all, default uses the default set, or a list such as Bash,Edit,Read. Does not affect MCP tools. See [Q2: Why are Glob and Grep loaded in this session?](question.q2.md).
