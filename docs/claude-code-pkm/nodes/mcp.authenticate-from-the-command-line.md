# Authenticate from the command line

**Sources:** [S31](src.s31.md)

The `claude mcp login ` command runs a configured server's OAuth flow directly from your shell, so you don't need to open the `/mcp` panel inside a session. For a claude.ai connector, follow Authorize a connector again from your shell.
