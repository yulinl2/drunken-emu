# Q5 (doubt): Are this session's remote scheduling tools the same feature as RemoteTrigger?

**Sources:** [S6](src.s6.md), [S7](src.s7.md)

[RemoteTrigger](tool.remote-trigger.md) creates, updates, runs and lists cloud scheduled tasks, and backs the /schedule command. The remote create-trigger family, starting with [create_trigger](tool.remote-create-trigger.md), does the same job under other names. Next check: compare the input schemas and decide whether the names are aliases.
