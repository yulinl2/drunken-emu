# CLAUDE_CODE_BASH_EDIT_DIFF

**Sources:** [S81](src.s81.md)

Set to `0` to turn off the diff of the files that changed while a Bash command ran, or `1` to record it in every permission mode. Takes precedence over the `bashEditDiffEnabled` setting. Requires Claude Code v2.1.269 or later
