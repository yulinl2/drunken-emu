# Use skills in Cowork and cloud sessions

**Sources:** [S32](src.s32.md)

Cowork sessions and cloud sessions, including cloud scheduled tasks, don't read `~/.claude/skills/` on your machine. Both interactive and scheduled Cowork sessions load the skills enabled for your claude.ai account, synced at session start. Manage them from Customize in the Desktop app sidebar or from the skills settings on claude.ai.
