# CLAUDE_CODE_DISABLE_TERMINAL_TITLE

**Sources:** [S81](src.s81.md)

Set to `1` to disable automatic terminal title updates based on conversation context. This also skips the background small/fast-model request that generates a session title, and turns off status reports to your terminal
