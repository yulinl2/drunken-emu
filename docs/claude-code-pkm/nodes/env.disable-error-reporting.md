# DISABLE_ERROR_REPORTING

**Sources:** [S81](src.s81.md)

Set to any non-empty value, such as `1`, to opt out of error reporting. Setting it to `0` or `false` still opts out, unlike most on/off variables; unset the variable to turn error reporting back on
