# Add a marketplace from claude.ai

**Sources:** [S42](src.s42.md)

In terminal sessions where plugins sync from your claude.ai account, claude.ai can also list plugin marketplaces for you, such as your organization's plugin library and your own claude.ai uploads. You add one of these by its name rather than by a source. Adding a marketplace from claude.ai requires Claude Code v2.1.273 or later.
