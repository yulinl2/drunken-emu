# Send a draft

**Sources:** [S82](src.s82.md)

When you send a draft, Claude Code submits it the same way as a `/feedback` report, with the same retention, and deletes the draft from your machine. When you send from the card, it shows `✓ Sent`; when you send from the queue, it closes with a receipt ID.
