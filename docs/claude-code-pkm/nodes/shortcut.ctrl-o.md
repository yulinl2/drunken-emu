# Ctrl+O

**Sources:** [S83](src.s83.md)

Toggle transcript viewer (context: Shows detailed tool usage and execution, with a timestamp and the model used on each assistant message. Also expands lines that collapse by default, such as MCP calls, shown as a single `Called slack 3 times` line, and messages from your other sessions, shown as a one-line `Message from @` preview)
