# CLAUDE_CODE_RESTRICTED

**Sources:** [S81](src.s81.md)

Set to `1` to start the session in restricted mode, the same as passing `--restricted`. Claude Code ignores this variable in a settings file's `env` block. Requires Claude Code v2.1.248 or later
