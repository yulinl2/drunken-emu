# pluginConfigs

**Sources:** [S54](src.s54.md)

Holds `userConfig` values for a mod, keyed by the plugin's id, such as `acme-guard@acme-tools`, or its name and `@inline`, such as `first-mod@inline`, for one loaded with `--plugin-dir` (where: User or managed settings)
