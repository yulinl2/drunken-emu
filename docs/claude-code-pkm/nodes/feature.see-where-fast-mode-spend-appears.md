# See where fast mode spend appears

**Sources:** [S71](src.s71.md)

You see fast mode spend in a different place depending on how you signed in, so first run `/status` to check. If it shows a `Login method` row such as `Claude Max account`, you signed in with a Claude subscription. If it shows an `API key` row instead, your requests bill to a Claude Console organization.
