# Broken file: Settings Error

**Sources:** [S3](src.s3.md)

A user, project or local file with invalid JSON or a rejected value triggers a Settings Error. At an interactive start, a dialog offers to fix the file with Claude's help, to exit, or to continue without the broken settings.
