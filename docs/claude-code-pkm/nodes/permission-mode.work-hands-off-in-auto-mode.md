# Work hands-off in auto mode

**Sources:** [S67](src.s67.md)

Requires a supported model, and your organization can turn auto mode off (start with: `claude --permission-mode auto`, the built-in starting permission mode with v2.1.283 or later; isolation needed: None; a sandbox or container adds defense in depth)
