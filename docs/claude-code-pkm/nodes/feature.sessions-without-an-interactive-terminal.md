# Sessions without an interactive terminal

**Sources:** [S52](src.s52.md)

`/reload-plugins` also runs in sessions without an interactive terminal, such as the desktop app, the Agent SDK, and non-interactive mode with `-p`. Requires Claude Code v2.1.260 or later.
