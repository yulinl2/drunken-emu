# filesystem.denyRead, a Read(...) deny rule, or a credentials.files entry

**Sources:** [S68](src.s68.md)

An `allowRead`, `allowWrite`, `Edit(...)` allow, or `additionalDirectories` entry at or under a path that managed settings, `--settings`, or user settings deny reading, or a glob that could match one (where you set it: Managed settings, `--settings`)
