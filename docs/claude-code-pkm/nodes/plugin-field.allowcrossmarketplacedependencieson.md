# allowCrossMarketplaceDependenciesOn

**Sources:** [S51](src.s51.md)

Marketplace names whose plugins may be installed as dependencies of this marketplace's plugins. When you install a plugin, only the list in that plugin's own marketplace applies, for its whole dependency chain. See Plugin dependencies (type: array of strings)
