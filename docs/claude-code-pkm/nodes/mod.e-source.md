# e.source

**Sources:** [S54](src.s54.md)

Who provides the skill: `policySettings`, `userSettings`, or `projectSettings` for a skill in the enterprise, personal, or project location, respectively. Other sources give a word such as `plugin`, `mcp`, `syncedSkills`, or `built-in`. (type: string)
