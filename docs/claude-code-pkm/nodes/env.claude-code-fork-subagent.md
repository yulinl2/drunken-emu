# CLAUDE_CODE_FORK_SUBAGENT

**Sources:** [S81](src.s81.md)

Controls fork mode, which is on by default and lets Claude start forks on its own. While fork mode is on, Claude also can't wait for a subagent in interactive terminal, VS Code, or desktop sessions on your machine. Set to `0` to turn fork mode off. For versions, see Turn fork mode off
