# Ctrl+W

**Sources:** [S83](src.s83.md)

Delete back to previous whitespace (context: Stores deleted text for pasting. One press removes a whole path or `--flag=value`. To delete only the previous word, press `Option+Delete` on macOS or `Ctrl+Backspace` on Windows)
