# TaskStop

**Sources:** [S82](src.s82.md)

Stops a running background task by ID. It also accepts an agent-team teammate or a named background agent by agent ID or name. When no task matches the ID, the error lists the running background agents by ID and description, including agents that another agent spawned (permission required: No)
