# Permission mode: plan

**Sources:** [S4](src.s4.md), [S6](src.s6.md), [S7](src.s7.md)

A mode name. Plan mode asks for approval of a plan ([ExitPlanMode](tool.exit-plan-mode.md)). A remote session started in plan mode waits for a person to approve.
