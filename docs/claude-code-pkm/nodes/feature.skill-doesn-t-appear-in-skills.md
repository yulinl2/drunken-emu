# Skill doesn't appear in /skills

**Sources:** [S40](src.s40.md)

cause: Skill file is at `.claude/skills/name.md` instead of in a folder; fix: Use a folder with `SKILL.md` inside: `.claude/skills/name/SKILL.md`.
