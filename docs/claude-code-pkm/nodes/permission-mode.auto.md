# Permission mode: auto

**Sources:** [S4](src.s4.md), [S6](src.s6.md)

A mode name. A classifier decides most prompts. Auto mode is in the Shift+Tab cycle by default; start in it with --permission-mode auto. It also reviews Monitor commands and WebSocket opens ([Monitor](tool.monitor.md)).
