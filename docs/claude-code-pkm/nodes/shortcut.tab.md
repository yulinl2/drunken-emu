# Tab

**Sources:** [S83](src.s83.md)

Accept an autocomplete suggestion, or add a comment to a permission answer (context: While autocomplete suggestions are showing in the prompt input, accepts the selected suggestion. On most permission prompts, with Yes or No focused, opens a comment field on that option, and pressing it again closes the field. See add a comment when you answer a permission prompt)
