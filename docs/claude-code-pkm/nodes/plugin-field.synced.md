# @synced

**Sources:** [S49](src.s49.md)

how the plugin got there: You or your organization turned it on for your claude.ai account, and Claude Code downloaded it; how you turn it on or off: On unless the manifest sets `defaultEnabled: false` or a settings file sets `"@synced": false`.
