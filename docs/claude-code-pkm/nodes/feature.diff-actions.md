# Diff actions

**Sources:** [S79](src.s79.md)

These actions reach only Claude Code's earlier diff viewer, which `/diff` opens outside fullscreen rendering after you disable the `cc-plugin-diff` mod in `/plugin`. While that mod is enabled, `/diff` opens the diff dialog instead. A `keybindings.json` that names these actions loads without errors either way.
