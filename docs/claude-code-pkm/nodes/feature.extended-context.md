# Extended context

**Sources:** [S70](src.s70.md)

Fable 5.1, Fable 5, Sonnet 5 and later, Haiku 5.5, Opus 4.6 and later, and Sonnet 4.6 support a 1 million token context window for long sessions with large codebases.
