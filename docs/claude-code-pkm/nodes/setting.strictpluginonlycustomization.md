# strictPluginOnlyCustomization

**Sources:** [S61](src.s61.md)

Treated as `true`, locking all four surfaces, when the value is neither a boolean nor an array. An array entry that this version doesn't recognize as a surface locks nothing; a status note counts such entries so you can check them for typos.
