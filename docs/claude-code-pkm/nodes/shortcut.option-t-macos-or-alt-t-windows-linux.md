# Option+T (macOS) or Alt+T (Windows/Linux)

**Sources:** [S83](src.s83.md)

Toggle extended thinking (context: Enable or disable extended thinking mode. Has no effect on Opus 5.5, Sonnet 5.5, Haiku 5.5, or the Fable models, which always use extended thinking. Works on macOS without configuring Option as Meta)
