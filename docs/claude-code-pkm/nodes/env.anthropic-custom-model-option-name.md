# ANTHROPIC_CUSTOM_MODEL_OPTION_NAME

**Sources:** [S81](src.s81.md)

Display name for the custom model entry in the `/model` picker. When not set, the entry shows the model's name if Claude Code recognizes the ID, and the model ID otherwise
