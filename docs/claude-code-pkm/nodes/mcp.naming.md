# MCP tool names

**Sources:** [S2](src.s2.md)

MCP tools are named mcp__<server>__<tool>. Plugin-bundled servers use mcp__plugin_<plugin>_<server>__<tool>. See [Matcher: MCP tool naming](hook-rule.matcher-mcp-naming.md).
