# Context and communication

**Sources:** [S27](src.s27.md)

Each teammate has its own context window. When spawned, a teammate loads the same project context as a regular session: CLAUDE.md, MCP servers, and skills. If you start the lead with `--setting-sources`, teammates load from the same restricted list of sources. Before v2.1.281, split-pane teammates loaded every settings source.
