# crossSessionInbound

**Sources:** [S12](src.s12.md)

Scope: any file. Type: string. Default: unset. Chooses whether messages from other sessions are accepted, held or refused. A stricter value from a project or local file is honored; see setting.managed-exception.cross-session-inbound.
