# Edit a saved script

**Sources:** [S29](src.s29.md)

To change a workflow you saved, edit its `.js` file or ask Claude to make the change. Before you edit or ask, run the `/workflow-authoring` bundled skill to load the script-writing reference Claude works from. The skill requires Claude Code v2.1.248 or later.
