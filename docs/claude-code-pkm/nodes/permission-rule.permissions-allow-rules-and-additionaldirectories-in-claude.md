# permissions.allow rules and additionalDirectories in .claude/settings.json

**Sources:** [S66](src.s66.md)

`permissions.allow` rules and `additionalDirectories` in `.claude/settings.json` (you trusted only a parent folder: Not used until you accept the trust dialog, which appears again listing them; `claude -p` or the sdk, folder never trusted: Not used. Claude Code prints a `this workspace has not been trusted` warning to stderr)
