# CLAUDE_CODE_PLUGIN_DIRS

**Sources:** [S54](src.s54.md)

Plugin directories to load as `--plugin-dir` does, for apps you can't pass a flag to. Absolute paths separated by `:`, or `;` on Windows. (where: Environment, or `env` in `~/.claude/settings.json`)
