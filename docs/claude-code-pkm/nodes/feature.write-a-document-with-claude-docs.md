# Write a document with Claude Docs

**Sources:** [S33](src.s33.md)

Claude Docs reaches Claude Code as a claude.ai connector rather than a command. When it's connected, `/mcp` lists it as `claude.ai Claude Docs`. A request for a document meant for other people then goes to Claude Docs instead of an artifact page: a spec, a proposal, or a write-up of the plan you worked through in the session. Claude gives you the doc's link when it's drafted.
