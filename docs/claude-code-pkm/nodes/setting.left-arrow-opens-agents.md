# leftArrowOpensAgents

**Sources:** [S12](src.s12.md)

Scope: global config (~/.claude.json); Claude Code ignores it in settings.json. Type: Boolean. Default: true. Pressing the left arrow on an empty prompt backgrounds the session and opens agent view; false turns the shortcut off.
