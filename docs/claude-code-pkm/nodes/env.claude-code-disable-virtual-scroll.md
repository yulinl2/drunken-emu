# CLAUDE_CODE_DISABLE_VIRTUAL_SCROLL

**Sources:** [S81](src.s81.md)

Set to `1` to disable virtual scrolling in fullscreen rendering and render every message in the transcript. Use this if scrolling in fullscreen mode shows blank regions where messages should appear
