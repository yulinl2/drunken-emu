# @skills-dir

**Sources:** [S49](src.s49.md)

how the plugin got there: You saved a plugin directory that has a `.claude-plugin/plugin.json` under `~/.claude/skills/` or the project's `.claude/skills/`; how you turn it on or off: The manifest's `defaultEnabled`, unless a settings file sets `"@skills-dir"` to `true` or `false`
