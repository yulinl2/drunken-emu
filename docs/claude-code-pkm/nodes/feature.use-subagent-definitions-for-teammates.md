# Use subagent definitions for teammates

**Sources:** [S27](src.s27.md)

When spawning a teammate in either display mode, you can reference a subagent type from the project, user, managed, or plugin subagent scope. This lets you define a role once, such as a security-reviewer or test-runner, and reuse it both as a delegated subagent and as an agent team teammate.
