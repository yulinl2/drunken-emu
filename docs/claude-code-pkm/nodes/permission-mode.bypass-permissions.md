# Permission mode: bypassPermissions

**Sources:** [S4](src.s4.md), [S7](src.s7.md)

Skips permission prompts. The flag --dangerously-skip-permissions equals it. --restricted refuses it. --allow-dangerously-skip-permissions adds it to the Shift+Tab cycle without starting in it.
