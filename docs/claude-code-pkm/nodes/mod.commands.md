# Commands

**Sources:** [S54](src.s54.md)

These commands and flags load, inspect, and test a mod. The `claude` commands run in your shell and the `/` commands at the Claude Code prompt. In the table, `` stands for a path you type, as in `claude plugin validate ./first-mod`. Square brackets mark an optional argument.
