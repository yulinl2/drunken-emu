# Ctrl+U

**Sources:** [S83](src.s83.md)

Delete from cursor to line start (context: Stores deleted text for pasting. Repeat to clear across lines in multiline input. On macOS, terminal emulators including iTerm2 and Terminal.app map `Cmd+Backspace` to this shortcut)
