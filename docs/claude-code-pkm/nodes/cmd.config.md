# /config

**Sources:** [S3](src.s3.md)

Opens the Config tab with personal options such as theme and editor mode. Saves to user settings, to local settings for a few options, or to ~/.claude.json for global keys. /config key=value sets one option directly. See [Settings file: user (~/.claude/settings.json)](setting-file.user.md).
