# Set options on the built-in guard

**Sources:** [S58](src.s58.md)

The built-in guard takes options. Set them in managed settings under `pluginConfigs`, keyed by `cc-plugin-sec-default@builtin`, as the example in Stop user-installed mods from loading does.
