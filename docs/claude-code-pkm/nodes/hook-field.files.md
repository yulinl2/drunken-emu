# files

**Sources:** [S85](src.s85.md)

Diffs of up to 5 changed files, for display. `created` or `deleted` is `true` for a file the command added or removed (type: array; example: `[{"filePath": "/path/to/src/app.ts", "hunks": [...]}]`)
