# Dynamic system-prompt sections

**Sources:** [S4](src.s4.md)

--exclude-dynamic-system-prompt-sections moves per-user context, such as the auto-memory location, out of the system prompt and into the first user message. It improves prompt-cache reuse across users. See [--exclude-dynamic-system-prompt-sections](flag.exclude-dynamic-system-prompt-sections.md).
