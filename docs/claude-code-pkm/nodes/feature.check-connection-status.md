# Check connection status

**Sources:** [S21](src.s21.md)

In an interactive session, while Remote Control is connected, the terminal shows an `/rc active` indicator that links to the session on claude.ai. The indicator is hidden when the terminal is too narrow to fit it. To see the session URL and a QR code for connecting from another device, run `/remote-control` again to open the status panel.
