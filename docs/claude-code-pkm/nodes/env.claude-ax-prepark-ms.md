# CLAUDE_AX_PREPARK_MS

**Sources:** [S81](src.s81.md)

In screen reader mode, how many milliseconds Claude Code waits before it writes a new or changed line. Default `0`, so Claude Code doesn't wait. Before v2.1.287, the default was `50`. Claude Code caps the wait at `5000`. Requires Claude Code v2.1.233 or later
