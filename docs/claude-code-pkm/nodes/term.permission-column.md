# Permission column

**Sources:** [S6](src.s6.md)

In the tools reference, Yes means the tool asks for approval in Manual mode for paths inside the working directory. File-access tools marked No still prompt for paths outside it. Bash runs a built-in set of read-only commands without asking. Example: [Bash](tool.bash.md).
