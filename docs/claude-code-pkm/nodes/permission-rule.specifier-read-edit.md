# Specifier: path patterns

**Sources:** [S6](src.s6.md)

Read(~/secrets/**) matches paths for Read, Grep, Glob and LSP. Edit(/src/**) matches paths for Edit, Write and NotebookEdit. See [Read](tool.read.md) and [Edit](tool.edit.md).
