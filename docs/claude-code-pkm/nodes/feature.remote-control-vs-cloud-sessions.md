# Remote Control vs cloud sessions

**Sources:** [S21](src.s21.md)

Remote Control and cloud sessions both use the claude.ai/code interface. The key difference is where the session runs: Remote Control executes on your machine, so your local MCP servers, tools, and project configuration stay available. A cloud session executes on cloud infrastructure, Anthropic-managed by default.
