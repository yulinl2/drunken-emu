# open, osascript, or browser-based auth flows fail with error -600 on macOS

**Sources:** [S68](src.s68.md)

The sandbox blocks Apple Events by default. Set `allowAppleEvents` to `true` in your user, managed, or CLI settings to allow them. Claude Code ignores this key in project settings.
