# Permission modes with the HIPAA configuration

**Sources:** [S67](src.s67.md)

In an organization with the HIPAA configuration applied, the built-in `auto` default doesn't apply. A terminal or VS Code session starts in Manual mode when nothing else chooses its starting permission mode.
