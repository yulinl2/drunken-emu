# --permission-mode

**Sources:** [S4](src.s4.md)

Starts in a permission mode: default, acceptEdits, plan, auto, dontAsk, bypassPermissions, or manual (an alias for default). Overrides defaultMode from settings. See [permissions.defaultMode limit](setting.permissions-default-mode-limit.md).
