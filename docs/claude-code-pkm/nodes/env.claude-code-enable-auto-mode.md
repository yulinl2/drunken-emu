# CLAUDE_CODE_ENABLE_AUTO_MODE

**Sources:** [S81](src.s81.md)

Accepted for compatibility with older releases and has no effect. Auto mode is available by default on every provider, including Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and signed-in Claude apps gateway sessions. In v2.1.158 through v2.1.206, setting this to `1` was required to make auto mode available on those providers
