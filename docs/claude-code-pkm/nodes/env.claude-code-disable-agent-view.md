# CLAUDE_CODE_DISABLE_AGENT_VIEW

**Sources:** [S81](src.s81.md)

Set to `1` to turn off background agents and agent view: `claude agents`, `--bg`, `/background`, and the on-demand supervisor. Equivalent to the `disableAgentView` setting
