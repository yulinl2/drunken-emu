# managed-only

**Sources:** [S19](src.s19.md)

Only your organization's managed `CLAUDE.md` and auto memory at launch. Your project, local, and user `CLAUDE.md` files, your `.claude/rules/` files, and every `AGENTS.md` are left out. A subdirectory's `CLAUDE.md` and `.claude/rules/` files, and path-scoped rules, still load on demand
