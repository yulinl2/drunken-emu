# When only managed permission rules apply

**Sources:** [S32](src.s32.md)

When your organization sets `allowManagedPermissionRulesOnly` in managed settings, Claude Code ignores `allowed-tools` in project and personal skills and in the other sources the setting's entry lists. This requires Claude Code v2.1.282 or later.
