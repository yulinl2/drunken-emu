# mcpServers

**Sources:** [S50](src.s50.md)

`.json` MCP config files, `.mcpb` or `.dxt` bundles, or inline server configs keyed by name. Loaded together with `.mcp.json`; a server name declared later replaces an earlier one (type: Path, object, or array of either)
