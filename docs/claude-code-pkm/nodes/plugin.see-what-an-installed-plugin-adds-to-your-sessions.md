# See what an installed plugin adds to your sessions

**Sources:** [S42](src.s42.md)

In your shell, run `claude plugin details ` for an installed plugin. The `Always-on` line is the number of tokens the plugin adds to every session where it's enabled, and the per-component rows show which skill or agent contributes most. For the full output and what each figure means, see Measure what a plugin costs.
