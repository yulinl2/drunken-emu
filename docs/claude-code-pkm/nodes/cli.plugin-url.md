# --plugin-url

**Sources:** [S52](src.s52.md)

Fetch a plugin `.zip` archive from a URL. Repeat the flag, or pass several URLs space-separated in one quoted value (example: `claude --plugin-url "https://example.com/a.zip https://example.com/b.zip"`)
