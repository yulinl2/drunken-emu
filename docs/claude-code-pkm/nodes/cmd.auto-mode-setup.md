# /auto-mode-setup

**Sources:** [S80](src.s80.md)

Draft `autoMode.environment` entries from your project and recent sessions, then review the draft and save it to your user settings. On a Pro, Max, or Team plan, requires Claude Code v2.1.228 or later, or v2.1.233 or later on native Windows. On an Enterprise plan or with a Claude Console API key, requires v2.1.283 or later. If the command is missing, see `/auto-mode-setup` returns "Unknown command"
