# Reverse search with Ctrl+R

**Sources:** [S83](src.s83.md)

Press `Ctrl+R` to interactively search through your command history. In fullscreen rendering, `Ctrl+R` opens a search dialog instead: type to filter, press `Up` and `Down` to move through matches, and press `Ctrl+S` to cycle the scope through this session, this project, and all projects.
