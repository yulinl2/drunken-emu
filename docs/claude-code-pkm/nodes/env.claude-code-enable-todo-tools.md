# CLAUDE_CODE_ENABLE_TODO_TOOLS

**Sources:** [S81](src.s81.md)

Set to `1` to get the task-tracking tools on every model. Without it, Claude Code provides them by default only on the models listed under Task tool availability. `CLAUDE_CODE_ENABLE_TASKS` still selects the Task tools or `TodoWrite`. Requires Claude Code v2.1.233 or later
