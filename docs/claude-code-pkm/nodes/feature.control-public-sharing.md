# Control public sharing

**Sources:** [S33](src.s33.md)

Public sharing is off by default on Team and Enterprise plans. To let members publish artifacts to public links that anyone can view without signing in, go to Organization settings > Artifacts and turn on External sharing under the Artifacts toggle. Turning it back off blocks access through existing public links without changing each artifact's audience; access resumes if you re-enable it.
