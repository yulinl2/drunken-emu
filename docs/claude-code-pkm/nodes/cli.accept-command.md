# --accept-command

**Sources:** [S52](src.s52.md)

Accept the displayed install command whose `sha256` a previous `--json` run reported in `shownCommand`, in place of `-y`. Can't be combined with `-y`. See Accept a displayed install command. Requires Claude Code v2.1.271 or later
