# CLAUDE_CODE_SYNTAX_HIGHLIGHT

**Sources:** [S81](src.s81.md)

Set to `false` to disable syntax highlighting in diff output. Useful when colors interfere with your terminal setup. To also disable highlighting in code blocks and file previews, use the `syntaxHighlightingDisabled` setting
