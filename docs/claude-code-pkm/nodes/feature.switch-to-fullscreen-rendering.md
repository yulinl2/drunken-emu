# Switch to fullscreen rendering

**Sources:** [S74](src.s74.md)

In screen reader mode, this section doesn't apply. Claude Code always renders as plain scrolling text except in attached background sessions, and if you run `/tui fullscreen` in any other session, Claude Code prints an explanation instead of switching.
