# Auto-connect with DISABLE_TELEMETRY or DO_NOT_TRACK set

**Sources:** [S21](src.s21.md)

With only `DISABLE_TELEMETRY` or `DO_NOT_TRACK` set, your sessions don't auto-connect through your organization's admin default or Claude Code's own default. If something else makes Remote Control unavailable for you, such as `DISABLE_GROWTHBOOK` or an LLM gateway, start with Requirements instead.
