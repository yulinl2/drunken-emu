# --mcp-config

**Sources:** [S4](src.s4.md)

Loads MCP servers from JSON files or strings. With -p, waits up to the MCP_TIMEOUT startup timeout for pending servers. See [MCP_TIMEOUT](env.mcp-timeout.md).
