# See which mods a session loaded

**Sources:** [S53](src.s53.md)

To see which mods a terminal session loaded, run `/plugin` at the Claude Code prompt. A dim line under the tabs gives the count and the names, such as `1 mod active · first-mod`. If a mod you installed isn't named there, see Find out why a mod does nothing.
