# Watch your changes in the diff panel

**Sources:** [S75](src.s75.md)

In fullscreen rendering, `/diff` opens a panel beside the conversation, so you can watch the changes accumulate while Claude works. Diff panel covers what it shows, when it opens on its own, how to keep it closed, and how to change what it compares against.
