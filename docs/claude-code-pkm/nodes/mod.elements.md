# Elements

**Sources:** [S54](src.s54.md)

Elements are the building blocks of a tree a `ui.render` hook returns, and you get them from `$.ui.resolve(e)`. Build a tree from elements shows the common ones with how the terminal draws them, and the interface gallery has screenshots of most. A check mark means the app can draw the element.
