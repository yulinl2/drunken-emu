# maxEffortLevel

**Sources:** [S12](src.s12.md)

Scope: any file. Type: string, low, medium, high, xhigh or max. Default: unset (no cap). Caps the effort level a session can use; higher levels run at the cap. A lower cap from any scope is honored even over managed settings; see setting.managed-exception.max-effort-level.
