# Lazy load by viewing a file

**Sources:** [S6](src.s6.md)

Subdirectory CLAUDE.md files and path-scoped rules also load when Claude views a file with cat, nl, bat, batcat, head, tail, sed -n, grep, egrep, fgrep or rg on one file, with no pipes or redirects.
