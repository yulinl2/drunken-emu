# --disallowedTools (alias --disallowed-tools)

**Sources:** [S4](src.s4.md)

Deny rules. A bare tool name removes the tool from context; a scoped rule denies only matching calls. See [Rule form: ToolName(specifier)](permission-rule.form.md).
