# When your context fills up

**Sources:** [S17](src.s17.md)

Claude Code compacts automatically as you approach the limit, so a full context window doesn't end your session. The automatic pass works the same way as the `/compact` step in the timeline. See When context fills up for what it preserves. For when Claude Code also compacts a conversation you leave idle, see idle compaction.
