# chat:sendNow

**Sources:** [S79](src.s79.md)

Send your queued messages, and your draft with them, right away. When Claude Code sends what you queued covers what happens to the turn Claude is working on. When nothing is running, the key submits the draft, and in shell mode it only queues the command. Terminals that don't report extended keys deliver `Ctrl+Enter` as plain `Enter`, so `Ctrl+X Ctrl+S` is the binding that works in any terminal. Requires v2.1.275 or later (default: Ctrl+Enter, Ctrl+X Ctrl+S)
