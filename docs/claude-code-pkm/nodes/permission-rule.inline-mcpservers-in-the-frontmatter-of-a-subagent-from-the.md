# Inline mcpServers in the frontmatter of a subagent from the repository or an --add-dir directory

**Sources:** [S66](src.s66.md)

Inline `mcpServers` in the frontmatter of a subagent from the repository or an `--add-dir` directory (you trusted only a parent folder: Not used, and no dialog is offered; `claude -p` or the sdk, folder never trusted: Not used)
