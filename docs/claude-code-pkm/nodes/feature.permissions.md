# Permissions

**Sources:** [S27](src.s27.md)

Teammates start with the lead's permission mode, except `dontAsk` mode, which they don't inherit. If the lead runs with `--dangerously-skip-permissions`, all teammates do too. After spawning, you can change an individual teammate's permission mode, but you can't set per-teammate permission modes at spawn time.
