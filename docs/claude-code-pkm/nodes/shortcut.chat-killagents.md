# chat:killAgents

**Sources:** [S79](src.s79.md)

Stop all running background subagents in this session and turn off artifact auto-replies for the rest of it. Press the shortcut twice within 3 seconds to confirm. You can press it while a background subagent's permission prompt is open (default: Ctrl+X Ctrl+K)
