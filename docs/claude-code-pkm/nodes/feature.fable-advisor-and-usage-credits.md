# Fable advisor and usage credits

**Sources:** [S72](src.s72.md)

On some plans, Fable usage bills to usage credits, and Fable as the advisor bills the same way. If your account requires the one-time consent to bill Fable usage to usage credits, Claude Code asks for it when you select a Fable model with `/model` and doesn't apply Fable as the advisor until you have accepted that consent.
