# sandbox.allowUnsandboxedCommands

**Sources:** [S12](src.s12.md)

Scope: any file, with a limit on project and local. Type: Boolean. Default: true. Lets Claude retry sandbox-blocked commands unsandboxed; false enables strict sandbox mode.
