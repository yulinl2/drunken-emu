# Ctrl+X Ctrl+K

**Sources:** [S83](src.s83.md)

Stop all running background subagents in this session, and turn off artifact auto-replies for the rest of it. Press twice within 3 seconds to confirm. You can press it while a background subagent's permission prompt is open (context: Subagent control)
