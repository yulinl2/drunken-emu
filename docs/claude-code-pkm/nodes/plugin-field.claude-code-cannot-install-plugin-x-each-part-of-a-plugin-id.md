# Claude Code cannot install plugin "x". Each part of a plugin id (plugin@marketplace) may use only the letters a-z and A-Z, digits, ".", "_" and "-", and must start with a letter or digit. Change this entry's "name".

**Sources:** [S51](src.s51.md)

level: Error; field: `plugins[i].name`
