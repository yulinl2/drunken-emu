# Set run limits and tools in prompt.md

**Sources:** [S47](src.s47.md)

Set a case's `max_turns`, `timeout_seconds`, `model`, `tags`, and the `allowed_tools` it may use in `prompt.md` frontmatter; the prompt.md frontmatter reference lists every field and its default.
