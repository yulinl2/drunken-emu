# permissions.defaultMode

**Sources:** [S12](src.s12.md)

Scope: any file; auto and bypassPermissions are not honored from project or local files. Type: string, one of default, acceptEdits, plan, auto, dontAsk, bypassPermissions or manual. Default: unset. Sets the permission mode that new sessions start in.
