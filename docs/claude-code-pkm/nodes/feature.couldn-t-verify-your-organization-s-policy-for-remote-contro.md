# "Couldn't verify your organization's policy for remote control"

**Sources:** [S21](src.s21.md)

Claude Code couldn't fetch your organization's policy and has no saved copy on this machine to use instead, so it keeps Remote Control off until it can confirm that your organization allows it. This usually happens when you start Claude Code offline or before a VPN connects, or when a proxy interferes with the request.
