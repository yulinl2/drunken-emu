# setMode

**Sources:** [S85](src.s85.md)

Changes the permission mode. Valid modes are `default`, `auto`, `acceptEdits`, `dontAsk`, `bypassPermissions`, `plan`, and `manual` as an alias for `default` (fields: `mode`, `destination`)
