# footer:dismiss

**Sources:** [S79](src.s79.md)

Binding a key to this action has no effect, and a `keybindings.json` that names it remains valid. Before v2.1.281, Backspace and Delete were bound to it and dismissed the selected artifact link from the footer. (default: (unbound))
