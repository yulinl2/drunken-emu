# CLAUDE_CODE_ALT_SCREEN_FULL_REPAINT

**Sources:** [S81](src.s81.md)

Set to `1` to repaint the entire screen on every frame in fullscreen rendering instead of sending incremental updates. Use this if fullscreen mode shows stale or misplaced text fragments. Claude Code enables this automatically for background sessions and agent view on Windows
