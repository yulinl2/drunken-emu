# Elicitation

**Sources:** [S2](src.s2.md)

Fires when an MCP server asks for user input during a tool call. Matcher: MCP server name. Output: action (accept, decline or cancel) and content. Exit 2 declines with no dialog. See [MCP overview](mcp.overview.md).
