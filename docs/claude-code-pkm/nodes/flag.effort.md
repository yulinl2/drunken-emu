# --effort

**Sources:** [S4](src.s4.md)

Sets the effort level: low, medium, high, xhigh, max or ultracode. Overrides the modelSettings and effortLevel settings for this session. Ultracode requests xhigh effort with ultracode turned on (v2.1.203 or later). See [effortLevel and modelSettings](setting.effort-level.md).
