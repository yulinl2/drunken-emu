# D3: Tag every claim with its source type

Official pages change. Session sources have no URL, so a tag is the only way to show where a claim came from. Tags: [VERIFIED](tag.verified.md), [INDEX](tag.index.md), [SESSION](tag.session.md), [REPO](tag.repo.md), [UNVERIFIED](tag.unverified.md), [OPEN](tag.open.md) and [GAP](tag.gap.md).
