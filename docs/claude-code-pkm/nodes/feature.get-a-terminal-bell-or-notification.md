# Get a terminal bell or notification

**Sources:** [S74](src.s74.md)

When Claude finishes a task or pauses for a permission prompt, and you appear to be away from the terminal, it fires a notification event. See when each notification type fires for the exact timing. Surfacing this as a terminal bell or desktop notification lets you switch to other work while a long task runs.
