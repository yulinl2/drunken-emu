# Cancel the wait

**Sources:** [S83](src.s83.md)

Press `Esc` at an empty prompt, or `Ctrl+C`, while the lines show, or run `/rate-limit-options` and pick Don't continue automatically. Claude Code confirms with a line that starts `Automatic continue cancelled`.
