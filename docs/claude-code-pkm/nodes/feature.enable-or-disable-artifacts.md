# Enable or disable artifacts

**Sources:** [S33](src.s33.md)

To enable or disable artifacts for the whole organization, go to Organization settings > Artifacts and use the Artifacts toggle. On Enterprise plans with role-based access control, you can additionally scope artifacts to specific roles: go to Organization settings > Roles, edit a role, and set the Artifacts permission.
