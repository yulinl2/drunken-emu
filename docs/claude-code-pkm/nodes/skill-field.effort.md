# effort

**Sources:** [S32](src.s32.md)

Effort level when this skill is active. Overrides the session effort level. When you omit it, the level comes from the effort resolution order. Options: `low`, `medium`, `high`, `xhigh`, `max`; available levels depend on the model. (required: No)
