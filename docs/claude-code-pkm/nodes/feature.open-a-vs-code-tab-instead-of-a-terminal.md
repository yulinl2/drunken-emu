# Open a VS Code tab instead of a terminal

**Sources:** [S39](src.s39.md)

The VS Code extension registers its own handler at `vscode://anthropic.claude-code/open`, which opens a Claude Code editor tab rather than a terminal window. See Launch a VS Code tab from other tools for that URL's parameters.
