# remoteControlAtStartup

**Sources:** [S12](src.s12.md)

Scope: any file. Type: Boolean. Default: unset. Connects Remote Control automatically when each interactive session starts. A false value in a project or local file is honored; see setting.managed-exception.remote-control-at-startup.
