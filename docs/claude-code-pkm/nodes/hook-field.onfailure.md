# onFailure

**Sources:** [S85](src.s85.md)

Whether the action that triggered the hook goes ahead when the hook fails: `"continue"` or `"block"`. See Block the action when a hook fails for `"block"` and for leaving the field unset. Requires Claude Code v2.1.295 or later (required: no)
