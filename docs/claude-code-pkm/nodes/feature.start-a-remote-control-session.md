# Start a Remote Control session

**Sources:** [S21](src.s21.md)

You can start a Remote Control session from the CLI, the Claude Desktop app, or the VS Code extension. The CLI offers three invocation modes; the Desktop app and VS Code use the `/remote-control` command.
