# sandbox.network.tlsTerminate

**Sources:** [S12](src.s12.md)

Scope: user or managed. Type: object with optional caCertPath and caKeyPath. Default: unset. Makes the sandbox proxy terminate TLS to inspect HTTPS contents (experimental).
