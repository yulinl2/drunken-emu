# OTEL_METRICS_INCLUDE_RESOURCE_ATTRIBUTES

**Sources:** [S65](src.s65.md)

Include keys from `OTEL_RESOURCE_ATTRIBUTES` as attributes on metric datapoints (default value: `true`; example to disable: `false`)
