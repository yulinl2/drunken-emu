# Issue reference links

**Sources:** [S83](src.s83.md)

When Claude mentions an issue as `owner/repo#123`, you can click the reference to open it, as long as your terminal supports hyperlinks. If Claude Code doesn't detect hyperlink support in your terminal, set `FORCE_HYPERLINK` to `1` to turn the links on, or to `0` to keep references as plain text.
