# CLAUDE_CODE_FORCE_TERMINAL_IMAGES

**Sources:** [S81](src.s81.md)

Set to `1` to draw mod `Image` elements as pictures when your terminal draws kitty graphics protocol images with Unicode placeholders and you still see an `Image`'s dimmed `alt` text. See which terminals draw an `Image` and why this variable doesn't help inside tmux or screen
