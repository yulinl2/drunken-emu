# Control connector calls from artifacts

**Sources:** [S33](src.s33.md)

Connector calls from artifacts have their own toggle, separate from the Artifacts toggle that turns artifacts on or off. Go to Organization settings > Capabilities and use the Enable artifact connectors toggle. The same toggle governs connector calls from artifacts created in claude.ai conversations.
