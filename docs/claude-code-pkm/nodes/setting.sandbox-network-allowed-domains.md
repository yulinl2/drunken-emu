# sandbox.network.allowedDomains

**Sources:** [S12](src.s12.md)

Scope: any file, with limits on project and local; managed only if allowManagedDomainsOnly is set. Type: array of strings. Default: unset. Pre-allows outbound domains for sandboxed commands so that no prompt appears.
