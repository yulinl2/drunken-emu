# CLAUDE_CODE_ENABLE_TELEMETRY

**Sources:** [S81](src.s81.md)

Set to `1` to enable OpenTelemetry data collection for metrics and logging. Required before configuring OTel exporters. Set it in your shell, user settings, or managed settings. Ignored in project and local settings. See Monitoring
