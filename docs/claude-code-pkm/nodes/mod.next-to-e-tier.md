# next.to(e, tier)

**Sources:** [S54](src.s54.md)

Skips to a later tier, which is `append`, `builtin`, or `core`. `next.to(e, 'append')` skips the mods a user installed. Only a mod in `prependPlugins` or `appendPlugins` can call it.
